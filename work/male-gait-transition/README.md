# Blades of War — переход ходьба ↔ бег

Это отдельная интерактивная проба на основе последней модели с поправками кистей и стоп. Сами циклы не переделаны, прежние файлы не заменены.

## Как посмотреть

1. Распакуйте ZIP и откройте `index.html` в браузере с WebGL. Интернет не нужен. Автопоказ повторяет ходьбу, переход к бегу и возвращение к ходьбе. При системной настройке уменьшения движения он изначально выключен: нажмите «Пуск» или «Автопоказ».
2. Кнопки **«Ходьба» / «Бег»** под моделью выключают автопоказ и переключают движение с сохранением фазы. Их можно нажимать повторно, не дожидаясь окончания перехода. Кнопка **«Автопоказ»** запускает повтор заново, без скачка позы.
3. Ползунок фазы ставит на паузу. Если выбрать другую походку на паузе, нажмите **«Пуск»** для самого перехода. Кнопка **«Скорость ½»** замедляет и шаг, и переключение. Модель можно вращать пальцем или мышью, увеличивать двумя пальцами или колёсиком.
4. Для осмотра ног выберите **«Обе стопы»** и вид **«Сбоку»** или **«Сзади»**. Если 3D недоступно, откройте `transition_preview.mp4` или `transition_feet.mp4`: это один и тот же сценарий в двух ракурсах, без звука.

## Что изменено

Модель `male_hands_airfoot_trial.glb` — точная копия последней пробы; ходьба, бег, их дорожки и исходная длительность не изменены. В просмотрщике обе анимации идут по общей фазе шага: бег сдвинут на −3/32 цикла относительно ходьбы. Вес бега и частота шага изменяются постепенно. При смене направления на полпути сохраняются текущие фаза, вес и скорость изменения веса. Сетка также постепенно меняет приблизительную скорость.

Чтобы смешанные позы не опускали выбранную область подошв ниже пола, в просмотрщике добавлен небольшой плавный подъём корня по вертикали. Небольшая упреждающая поправка распределяет этот подъём по соседним фазам; на самих исходных циклах в проверенных фазах он не применяется. Это не закрепление ноги: горизонтальное скольжение возможно, а угол стопы по-прежнему стоит оценить визуально.

## Важно для использования в игре

**Переход не записан в GLB как отдельный клип.** Его выполняет код `phase-clock.mjs`, `floor-envelope.mjs` и `locomotion-three.mjs`, тот же код встроен в просмотрщик. Их можно использовать с Three.js (пакет `three`) как основу для отдельной интеграции:

```js
import {LocomotionTransition} from './locomotion-three.mjs';
// gltf — загруженный здесь GLB; добавьте gltf.scene в сцену.
const gait = new LocomotionTransition(gltf.scene, gltf.animations);
gait.setTarget('run');             // или 'walk'; можно менять в любой момент
// В каждом кадре, до рендеринга:
gait.step(deltaSeconds);           // обычное время, не накопленное
```

Контроллер предназначен для этого именованного рига и клипов, модели в исходном масштабе, ровного пола в мировой плоскости Y=0 и движения на месте. Все три файла кода должны лежать рядом. Не управляйте теми же костями другим микшером одновременно. Это демонстрационная реализация для Three.js, не готовая система передвижения в игровом движке; скорость сетки приблизительная, перемещение и физика персонажа не реализованы. При переносе в другой движок нужно отдельно воспроизвести фазировку, смешивание, ограничение пола и проверить контакты.

Выборочные проверки не гарантируют отсутствие пересечений во всех фазах или естественность. В исходной ходьбе ранее обнаруживались локальные пересечения треугольников правой стопы в 2 из 64 выбранных фаз; глубина и заметность не измерялись. Просьба оценить переход и сам угол стопы на обычной скорости.

# Blades of War — движение и присед

Это отдельная **управляемая проба** на ровной земле. В ней можно оценить переходы ходьбы и бега и более быстрый присед на нынешнем персонаже. Прежняя сцена `work/male-game-scene/` сохранена без изменений. Это ещё не готовая система стелса.

## Открыть

Распакуйте `BladesOfWar_Dvizhenie_i_Stels.zip` целиком и откройте `index.html` в современном браузере с WebGL. После распаковки интернет не нужен. Если репозиторий уже скачан, можно открыть `work/male-stealth-tuning/index.html`. Рядом находится короткий ролик `sravnenie.mp4` без звука: слева прежняя сцена, справа новая. Для сравнения камера в ролике показывает персонажа сбоку, удерживая его на открытом участке; это запись из обеих сцен, а не отдельная анимационная симуляция.

## Управление

- Нажмите на землю или удерживайте **WASD / стрелки**, чтобы двигаться. **Shift** во время движения или кнопка «Ходьба / Бег» выбирают бег; **Shift + щелчок** отправляет к точке бегом.
- **C / «Присесть»** переключает присед. Опускание начинается сразу, в том числе из бега; быстрое повторное нажатие меняет направление перехода без перезапуска позы. В приседе персонаж идёт медленнее. При вставании ранее выбранный темп сохраняется.
- **E / «Осмотреть»** или нажатие на колодец запускает подход и осмотр. **Esc** останавливает движение. Это пробное взаимодействие: вода, ведро и инвентарь не используются.
- Потяните сцену мышью или пальцем либо нажмите **↶ / ↷**, чтобы повернуть камеру. Кнопка «В начало» сбрасывает сцену; подсказка **?** находится наверху.

## Что изменено

- Переход ходьба ↔ бег теперь подстраивается под **фактическую скорость** персонажа, а не сразу под запрошенную максимальную. Во время ускорения к бегу контроллер больше не подмешивает стойку вместо движения. Общая фаза шагов и прежнее смещение бега −3/32 цикла сохранены.
- Для приседа проверена другая библиотечная анимация. В этой пробе циклы `Crouch_Idle_Loop` и `Crouch_Fwd_Loop` из **Quaternius Universal Animation Library Standard** перенесены на нынешний 52-костный риг и смешаны с прежним подогнанным приседом: коэффициент библиотечной части — 0,45. Подогнаны фазы и высота стоп; в неподвижном приседе выбранные точки обеих стоп дополнительно подведены к полу. Это **адаптация**, а не исходный клип без изменений. Переход в присед не взят из отдельного библиотечного клипа: его создаёт непрерывное смешивание в контроллере.
- Вход и выход теперь используют быстро реагирующий демпфированный переход; при входе из бега также ускорено плавное торможение. В тесте при 60 кадрах/с вес приседа достигает 10% через **0,05 с**, 90% — через **0,27 с** из стойки, ходьбы и бега. В прежней сцене из бега те же отметки были приблизительно **0,52 и 0,80 с**. Это измерение веса смешивания, а не оценка реализма или завершения любого движения стопы.
- Модель `work/male-leg-volume/male_leg_volume_trial.glb` и код колодца не менялись. Дополнительные движения выполняются в коде страницы и не записаны в исходный GLB.

## Ограничения

- Фиксации стоп по горизонтали и физики контакта нет: скольжение, небольшие зазоры и рывки в отдельных фазах по-прежнему возможны. Для ровного пола применяется вертикальная коррекция и ограниченная подгонка ног. Это не обещание идеального контакта или отсутствия всех пересечений.
- Подъём по склону, лестницы, полноценная физика, обнаружение врагами и другие механики стелса сюда не включены. Коллизия колодца приближена окружностью.
- Проведены выборочные браузерные и геометрические проверки; это не заменяет визуальной оценки всех фаз. Проверка касаний выполнена в эмуляции браузера, **физический телефон не проверен**. Производительность на слабых устройствах может отличаться. Системная настройка уменьшения движения отключает дыхание в стойке.

## Сборка и проверка

Исходники находятся в `tools/male-stealth-tuning/`. Из корня репозитория:

```sh
npm ci --prefix tools/male-stealth-tuning
npm run build --prefix tools/male-stealth-tuning
npm test --prefix tools/male-stealth-tuning
```

Для браузерного теста нужны зависимости `tools/character-showcase` и Chromium; при необходимости задайте `CHROME_BIN`. Результаты локальной и HTTP-проверок — `qa-offline.json` и `qa-http.json`. Проверены управление мышью и клавиатурой, четыре эмулированных мобильных размера, маршруты, осмотр колодца, смены темпа и прерывания приседа. Выборочная проверка 96 поз для выбранных областей кистей, стоп, коленей и таза описана в `collision-report.json`; для её повторения нужны NumPy и python-fcl:

```sh
node tools/male-stealth-tuning/export-collision-samples.mjs /tmp/bow-stealth-poses.json
python3 tools/male-stealth-tuning/qa-collision.py /tmp/bow-stealth-poses.json --strict
```

Большой JSON с вершинами — временный файл, его не нужно добавлять в репозиторий. `record.mjs` записывает сравнение; нужны FFmpeg с libx264 и drawtext. После всех проверок `python3 tools/male-stealth-tuning/package.py` сверяет хеши и собирает архив.

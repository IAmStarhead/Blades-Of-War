# Отдельная проба затылка мужчины

Пользователь заметил вертикальную полосу на затылке в предыдущей витрине. Она видна и в исходной модели, и в её облегчённой копии. При диагностике линия оставалась после отключения текстуры, но исчезала при равномерном тестовом освещении. Направления освещения соседних вершин около заднего центрального стыка меняются резко: это артефакт сглаживания поверхности, а не нарисованный шрам.

## Посмотреть пробу

**Через GitHub Desktop:**

1. Один раз клонируйте `https://github.com/IAmStarhead/Blades-Of-War.git` и выберите ветку `arena/4319905c-blades-of-war` в меню **Current branch**.
2. Выберите **Repository → Show in Explorer** (на macOS — **Show in Finder**), откройте папку `work/male-nape-seam` и дважды нажмите `index.html`. Страница откроется в обычном браузере с поддержкой WebGL, а не внутри GitHub Desktop.
3. Чтобы получить дальнейшие изменения в этой ветке, нажмите **Fetch origin**, а затем, если появится, **Pull origin**. Обновите открытую страницу в браузере. Отдельные последующие пробы могут находиться в других папках.

Первое клонирование загружает весь репозиторий, включая архивы; при дальнейшей синхронизации GitHub Desktop загружает изменения. Витрина содержит модели внутри HTML, поэтому после синхронизации открывается без интернета и без распаковки ZIP.

Можно также [скачать ZIP](BladesOfWar_Proba_Zatylka.zip?raw=1), распаковать его и открыть `BladesOfWar_Zatylok.html`. В обоих случаях витрина открывается крупным планом затылка.

- **«До»** — прежняя облегчённая модель; **«После»** — отдельная проба сглаживания; **«Исходная»** — неизменённый первоначальный мужчина, на нём переход тоже остаётся. Переключение не меняет положение камеры и свет.
- Камеру можно вращать мышью, пальцем или стрелками; **«Начальный вид»** возвращает начальный поворот.
- Сохранены **«Сверху»**, **«Обычный»** с колодцем и **«Осмотр»** в полный рост. **«Затылок»** показывает голову крупнее. В двух последних ракурсах колодец временно скрыт, чтобы не мешать осмотру. Это камера витрины, не изменение игровой камеры.

## Что именно изменено

Копия облегчённой модели сохраняет **32 354 треугольника**. У 437 вершин на затылке изменены только нормали — направления, по которым рассчитывается освещение; максимальное изменение направления примерно 3,96°. Положения вершин, соединения треугольников, UV, цвета, текстура, материалы, тело, уши и иерархия не менялись. Исходный и прежний облегчённый GLB, код подробного колодца и предыдущий ZIP сохранены.

Это локальная проба, а не заявленная окончательная модель: видимый результат зависит от освещения и должен быть оценён владельцем. Женщина не добавлена; руки расслаблены, статичная проба кулаков выключена. Рига, анимации и системы отсечения нет; игровая производительность не проверялась.

## Проверки

- glTF Validator: 0 ошибок и 0 предупреждений до и после, по 32 354 треугольника.
- Побайтово сравнены все индексы и атрибуты, кроме изменённых локальных нормалей головы. Проверены нормализация и совпадение дублирующихся нормалей, материалы, текстура и мировые матрицы.
- При одинаковой камере и свете прежние варианты из новой и старой витрин дали попиксельно одинаковые кадры для вида сверху и обычного вида, шесть поворотов на вариант.
- В крупном плане затылка измерен максимальный соседний скачок яркости в проверочной полосе: при стандартном свете **2,861 → 0,430 из 255**. При двух дополнительных направлениях освещения скачок тоже уменьшился; это не гарантия для любого света. Фронтальный тестовый кадр до и после совпал попиксельно. Подробности — `seam-comparison.json`.
- Проверены четыре ракурса и восемь поворотов на нескольких размерах экрана, управление мышью и пальцем, запрет свободного zoom/pan, автономное открытие, CRC и воспроизводимость сборки.

## Воспроизведение

Сборщик использует предыдущий архив `work/male-camera-dual-view/BladesOfWar_Dva_Rakursa.zip` и не меняет его. Нужны Node.js, Python, зафиксированные в `package-lock.json` зависимости; для браузерного QA — Chromium и системные библиотеки:

```bash
npm ci --prefix tools/male-nape-seam
npm ci --prefix tools/character-showcase
python3 tools/male-nape-seam/build.py
python3 tools/male-nape-seam/verify.py --rebuild
node tools/male-nape-seam/qa-gltf.mjs
node tools/male-nape-seam/qa-browser.mjs --scope=basic
node tools/male-nape-seam/qa-browser.mjs --scope=previous
node tools/male-nape-seam/qa-browser.mjs --scope=seam
```

Предыдущий и новый архивы содержат тексты лицензий CC0 для указанных базовых ресурсов и MIT для Three.js; это не объявляет всю игру CC0 или MIT.

# Мужчина и колодец — витрина с двумя ракурсами

Новая отдельная версия предыдущей витрины. Выбранный мужчина, его облегчённая копия и подробный колодец **не переделывались**; прежний архив сохранён. В этой витрине женщины нет, кисти расслаблены, проба кулаков выключена.

## Как открыть и пользоваться

[Скачать ZIP с витриной и двумя моделями](BladesOfWar_Dva_Rakursa.zip?raw=1). Распакуйте архив и откройте `BladesOfWar_Showcase.html` в браузере с WebGL; для просмотра интернет не нужен.

В нижней панели:

- **«Сверху»** — прежний игровой ракурс с мужчиной и колодцем.
- **«Обычный ракурс»** — отдельный вид мужчины в полный рост, почти на уровне человека. Колодец в этом режиме временно скрывается; при возврате к виду сверху он снова виден. Это режим осмотра в витрине, а не новая игровая камера.
- **«Исходная» / «Облегчённая»** переключают две модели в одной и той же позе, без смены камеры и света. В них соответственно **287 782** и **32 354** треугольника.
- Камеру можно вращать мышью, пальцем или стрелками. Для каждого режима запоминается поворот; кнопка **«Начальный вид»** возвращает начальное направление текущего режима.

Режимы имеют разные фиксированные дистанции для показа; свободное приближение колесом или жестом и сдвиг отключены. Риг, анимация и система отсечения по-прежнему не реализованы; это не готовая игровая модель.

## Что сохранено и проверено

Новая витрина собрана из предыдущего архива `work/male-camera-optimization/BladesOfWar_Male_Fixed_Camera.zip` с SHA-256 `3cc9da6d6264822a0957cec0cf533dbffff15a0d6cbbf556bd6ed0877afb2a82`. Встроенные и отдельные GLB в новом ZIP совпадают с прежними побайтно:

- исходный мужчина — `450d660b03b284fdb4e3c9363a6211c02525311096d2cd9da69449e9f84a85b3`;
- облегчённый мужчина — `ee4fee7388eaf3e77ba01061e11d9a569e6e8684ce349ab86981a9408b33b5c3`.

Код подробного колодца и движка также скопирован из прошлого архива. При одинаковой камере проверенные рендеры вида сверху совпали с прошлой витриной попиксельно для обеих моделей и шести направлений. На обычном ракурсе две версии сравнивались на восьми направлениях: различия в пикселях есть, так как облегчённая голова не является математически точной копией. Решение о внешнем сходстве остаётся за владельцем.

Офлайн-проверки Chromium охватили оба ракурса и восемь поворотов на настольных и мобильных размерах, переключение моделей, сохранение поворотов, мышь, одно- и двухпальцевые жесты. Обе модели прошли glTF Validator с 0 ошибок и предупреждений. Проверены CRC ZIP, лицензии и побайтовая повторная сборка. Это не проверка игровой производительности или будущих деформаций.

## Воспроизведение

Сборщик использует только Python и предыдущий проверенный ZIP; при пересборке исходный архив не меняется. Для браузерного QA нужен Chromium с системными библиотеками, либо `CHROME_BIN`, и зависимости инструмента предыдущей витрины:

```bash
python3 tools/male-camera-dual-view/build.py
python3 tools/male-camera-dual-view/verify.py --rebuild
npm ci --prefix tools/character-showcase
node tools/male-camera-dual-view/qa-browser.mjs --scope=basic
node tools/male-camera-dual-view/qa-browser.mjs --scope=old-scene
node tools/male-camera-dual-view/qa-browser.mjs --scope=normal-compare
```

Предыдущий архив и новый ZIP содержат тексты лицензий CC0 для указанных базовых ресурсов и MIT для Three.js; они не объявляют всю игру CC0 или MIT.

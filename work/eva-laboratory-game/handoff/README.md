# Перенос материалов отдельной игры

Три архива дополняют друг друга и рассчитаны на распаковку **в один корень нового проекта**. Они не содержат готовой игры или Git-истории старого репозитория.

## Скачать

1. [Описание игры — `01_game_documents.zip`](01_game_documents.zip?raw=1): концепция, дизайн героини и одежды, предварительная проверка названия, заметка о переносе.
2. [Концепт-арты — `02_concept_art.zip`](02_concept_art.zip?raw=1): два белых лабораторных интерьера и две пробы одежды с пояснениями. Изображения сгенерированы нейросетью, это не готовые игровые уровни и не рендеры модели.
3. [Модель героини — `03_heroine_model.zip`](03_heroine_model.zip?raw=1): GLB с пробой ушей, сохранённый исходный GLB, автономная витрина, сравнения и лицензии компонентов.

[Контрольные суммы архивов](SHA256SUMS). В комплект попали только выбранные материалы; неудачные серые пробы и найденные в интернете фотографии не включены. Исходные файлы в этом репозитории сохранены.

## Как перенести

1. Создайте пустую папку для новой игры. Распакуйте **содержимое каждого из трёх ZIP в эту же папку**, соглашаясь на объединение папок. Не распаковывайте их в три разные вложенные папки с именами архивов: внутренние ссылки рассчитаны на общий корень.
2. В общей папке должны появиться `README.md`, `CHARACTER_DESIGN.md`, `NAME_CHECK.md`, `TRANSFER_NOTE.md` и папки `concept-art` и `models`. Документы связываются с картинками и моделью после распаковки всех трёх архивов.
3. В новый репозиторий перенесите **файлы и папки из этой общей папки**, не сами ZIP. Если в новом репозитории уже есть одноимённые файлы, сначала сохраните их и проверьте замены.
4. Для интерактивного просмотра откройте локально `models/heroine/Heroine_Showcase.html` в браузере с WebGL. Интернет не нужен. Файл содержит пробу героини; колодец в витрине — старый объект для просмотра, не часть утверждённого мира новой игры.

Ни название **Gen**, ни имя героини **Ева / Джин** окончательно не утверждены. Модель — заготовка без скелета, одежды и полноценного боевого рига; моргание и предварительные кулаки в ней сохранены. Цель по производительности на ноутбуке ещё не проверялась.

## Проверка и сборка этого комплекта

Материалы взяты из состояния репозитория `7fa31c89134f0b54d83a25a3ed8b4321a97113cf`; выбранные PNG, GLB и сравнения проверяются по SHA-256. Сборщик только переадресует ссылки в документах и меняет видимые названия витрины; геометрию и код просмотрщика не меняет. Текст CC0 для MakeHuman/MPFB2 assets и MIT для Three.js r187 находятся рядом с моделью. Это не общая лицензия всех материалов игры.

Из корня **старого** репозитория при Python 3.11:

```bash
python3 tools/eva-laboratory-handoff/build.py --output /tmp/laboratory-handoff
python3 tools/eva-laboratory-handoff/verify.py --result /tmp/laboratory-handoff
# Для браузерной проверки нужны npm-зависимости tools/character-showcase и Chromium:
npm ci --prefix tools/character-showcase
node tools/eva-laboratory-handoff/qa-viewer.mjs /tmp/laboratory-handoff
```

Проверены CRC и SHA архивов, распаковка всех 21 файлов без перезаписи, относительные ссылки, соответствие оригиналам и встроенная в HTML модель; два GLB прошли Khronos Validator без ошибок и предупреждений. Автономный просмотрщик проверен в Chromium без сети, включая ракурсы ушей, моргание и кулаки. Эти проверки не подтверждают художественное одобрение или FPS будущей игры.

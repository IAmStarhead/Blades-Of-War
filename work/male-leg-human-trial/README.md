# Отдельная проба движения ног

Откройте **[интерактивную сцену](index.html)** в современном браузере с WebGL. Это самостоятельная страница: модель и код встроены, после скачивания интернет не нужен. Прежние сцены и исходный GLB не изменены.

Для сравнения: **[обзор с картинками и видео](study.html)** · **[видео до/после](comparison.mp4)** · **[подробное исследование](RESEARCH.ru.md)**. Видеоролик показывает обе пробы с четырёх сторон; отметки на земле существуют только в ролике.

## Управление

- Нажмите на землю или используйте **WASD / стрелки**. **Shift** или кнопка темпа переключают бег.
- **C / «Присесть»** переключает присед, в том числе во время движения. В приседе персонаж идёт медленно.
- Потяните сцену или нажмите **↶ / ↷** для поворота камеры. **+ / V** включает крупный план персонажа; **− / V** возвращает общий план.
- **E / «Осмотреть»** или нажатие на колодец запускают подход и пробную анимацию. **Esc** останавливает движение; «В начало» сбрасывает сцену.

## Результат и границы

Ходьба в приседе адаптирована из записи 100STYLE через HumanMotionCraft: другой риг, вырезанный и замедленный цикл, подъем стопы и подгонка опоры. Неподвижный присед сконструирован симметричным по одному кадру, а не записан. Обычные ходьба и бег **не исправлялись** в этой пробе. Подгонка уменьшает наблюдаемое движение некоторых точек у пола в прямолинейном тесте, но динамической фиксации стоп и физики контакта нет; скольжение и ошибки деформации всё ещё возможны. Сравнения ограничены немногими записями и не являются медицинской нормой.

Проверены браузер, выборочные переходы, 96 поз выбранных областей сетки и четыре мобильных размера с эмуляцией касаний. Физический телефон, все повороты, все возможные пересечения и движение по склону не проверены. Подробные результаты и оговорки — в [исследовании](RESEARCH.ru.md); источники и условия — в [CREDITS.md](CREDITS.md).

## Сборка и повторение проверок

В полном репозитории, из его корня (Node.js 22 и npm):

```sh
npm ci --prefix tools/male-leg-human-trial
npm run build --prefix tools/male-leg-human-trial
npm ci --prefix tools/character-showcase   # зависимости браузерных тестов
npm test --prefix tools/male-leg-human-trial
npm run check:contact --prefix tools/male-leg-human-trial
python3 tools/male-leg-human-trial/compare-kinematics.py  # нужен NumPy
```

Сборка проверяет SHA входов, пересоздаёт `tools/male-leg-human-trial/crouch-clips.json` и затем записывает `work/male-leg-human-trial/index.html`; чтобы сохранить HTML в новый каталог вне репозитория, используйте `npm run build --prefix tools/male-leg-human-trial -- --output /tmp/leg-trial-build`. Браузерные тесты требуют Chromium; при необходимости задайте `CHROME_BIN`. `qa-offline.json`, `qa-http.json` и `foot-contact-report.json` относятся к SHA-256 готового HTML.

Для просмотра исследования и перемотки видео через локальный HTTP можно запустить `PORT=4363 node tools/male-leg-human-trial/serve.mjs` и открыть `http://localhost:4363/study.html` на том же компьютере. При работающем сервере `npm run test:report --prefix tools/male-leg-human-trial` проверяет ссылки, размеры страницы и перемотку видео. В интерактивной предпросмотр-среде используйте предоставленную ей ссылку, а не `localhost`.

Для публикации через GitHub Pages подготовлена побайтовая копия этой папки в `docs/male-leg-human-trial/`. При настройке сайта на каталог `/docs` текущей ветки файл `docs/.nojekyll` оставляет файлы без преобразования Jekyll. После правок в оригинале копию нужно обновить, сохраняя другие файлы в `docs/`.

Для повторения выборочной проверки поверхности нужны NumPy и `python-fcl`:

```sh
node tools/male-stealth-tuning/export-collision-samples.mjs /tmp/leg-trial-poses.json "file://$(pwd)/work/male-leg-human-trial/index.html"
python3 tools/male-stealth-tuning/qa-collision.py /tmp/leg-trial-poses.json --report /tmp/leg-trial-collision.json --strict
```

Временный файл с вершинами большой и не входит в поставку. `tools/male-leg-human-trial/capture-kinematics.mjs` снимает 96 фаз для повторного численного сопоставления; исходные выбранные данные и ссылки на источники сохранены рядом с инструментом. `record.mjs` записывает видео в **новый** файл и требует Chromium, FFmpeg с libx264 и drawtext и шрифт DejaVu Sans. Скрипт `make-evidence.py` собирает контактные листы из промежуточных снимков; исходные видео и промежуточные снимки в архив не включены. Их ссылки, лицензии и хеши указаны в [CREDITS.md](CREDITS.md).

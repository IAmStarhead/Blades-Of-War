# Отдельная проба стелс-стойки

**[Открыть сцену](index.html)** · **[сравнение с видео и четырьмя ракурсами](study.html)** · **[прежняя сцена](../male-leg-human-trial/index.html)**

Это отдельная проба по замечанию о сутулом приседе. Корпус и взгляд подняты, таз опущен, руки слегка согнуты и расположены асимметрично. В ходьбе положение рук меняется по фазе шага. Предыдущая сцена и исходный GLB не изменены. Обычные ходьба и бег в этой пробе не переписывались.

Сцена `index.html` содержит модель и код и может работать без сети в браузере с WebGL. Для обзора с видео и ссылки на прежнюю сцену нужны также соседние файлы и папка `male-leg-human-trial`.

## Управление

- **C / «Присесть»** — войти в присед или встать; можно переключать и во время движения.
- **WASD / стрелки** или нажатие на землю — движение; **Shift** — бег вне приседа.
- Потяните сцену или нажмите **↶ / ↷** для поворота камеры. **+ / V** — крупный план персонажа.
- **E / «Осмотреть»** или нажатие на колодец — подойти и осмотреть; **Esc** — остановиться.

## Что изменено

За основу взяты опубликованные клипы предыдущей пробы на базе 100STYLE / HumanMotionCraft, а не новая запись движения. В 121 ключе каждого клипа таз опущен на 6 см для стойки и 11 см для ходьбы относительно прежней пробы; двухзвенный IK возвращает лодыжки к прежним целям и сохраняет ориентацию стоп. В стойке цели дополнительно разнесены на 4 см в сторону и на 5 см вперёд/назад для каждой ноги. Положение позвоночника, головы и рук задано заново; пальцы используют треки принятой ходьбы персонажа. Между ключами позы интерполируются, а во время переходов дополнительно применяется существующая коррекция пола. Это авторская адаптация, не физическая симуляция и не медицинская норма. Прежнее численное совпадение направлений ног с источником **не относится** к этой изменённой позе.

## Проверки и ограничения

- Сняты сравнимые позы с четырёх ракурсов, создано [18-секундное видео](comparison.mp4) одинаковых команд, просмотрены его выборочные кадры. В видео камера следует за персонажами, а отметки стоят на земле.
- Offline/HTTP браузерные проверки: 80 выбранных поз обычной ходьбы/бега совпадают с предыдущим вариантом до численной погрешности; проверены управление, 48 маршрутов, 64 фазовых перехода, прерывания приседа, касания на четырёх эмулированных размерах и работа с колодцем. Физический телефон не проверен.
- В девяти сценариях на ровном полу, с выборкой 60 Гц, проверено по 1091 вершине каждой стопы. Для кадров с весом приседа ≥ 0,95 хотя бы одна выбранная вершина была не выше 12 мм над расчётной плоскостью; выбранные вершины не проходили под пол. Бег после выхода может иметь фазу полёта. См. [ground-transitions.json](ground-transitions.json).
- В ограниченном прямолинейном тесте при 0,38 м/с максимальное горизонтальное перемещение одной выбранной вершины в эпизоде близости к полу — около 74 мм слева и 40 мм справа; это практически те же показатели, что у предыдущей пробы. См. [foot-contact-report.json](foot-contact-report.json). **Близость к полу не доказывает контакт, а смещение одной вершины не измеряет скольжение всей стопы.** Динамической фиксации стопы нет, поэтому при поворотах и переходах скольжение возможно.
- В 96 выборочных позах не найдено пересечений проверяемых областей кистей, стоп, коленей и таза ([collision-report.json](collision-report.json)). Это не проверка всей сетки, всех фаз или всех движений.

## Сборка и повторение

В полном репозитории, из его корня, нужны Node.js 22, npm и браузерные зависимости `tools/character-showcase`:

```sh
npm ci --prefix tools/male-stealth-posture-trial
npm run build --prefix tools/male-stealth-posture-trial
npm test --prefix tools/male-stealth-posture-trial
npm run check:contact --prefix tools/male-stealth-posture-trial
node tools/male-stealth-posture-trial/check-ground.mjs
```

Сборка проверяет SHA исходной модели и прежних клипов, пересоздаёт **только** `tools/male-stealth-posture-trial/crouch-clips.json` и `work/male-stealth-posture-trial/index.html`. Чтобы записать HTML в другую новую папку вне репозитория, добавьте `-- --output /tmp/posture-build` к команде сборки; файл клипов в папке инструментов при этом всё равно пересоздаётся. Браузерным тестам нужен Chromium; при необходимости задайте `CHROME_BIN`.

Для просмотра двух сцен и перемотки видео через HTTP: `PORT=4364 node tools/male-stealth-posture-trial/serve.mjs`. На том же компьютере откройте `http://localhost:4364/`; в среде удалённого предпросмотра используйте выданную ею ссылку, не localhost. Для GitHub Pages подготовлена копия в `docs/male-stealth-posture-trial/`, однако сам Pages нужно отдельно включить в настройках репозитория.

Проверка выборочных пересечений требует NumPy и `python-fcl`:

```sh
node tools/male-stealth-tuning/export-collision-samples.mjs /tmp/posture-poses.json "file://$(pwd)/work/male-stealth-posture-trial/index.html"
python3 tools/male-stealth-tuning/qa-collision.py /tmp/posture-poses.json --report /tmp/posture-collisions.json --strict
```

Исходники, условия и указание изменений — в [CREDITS.md](CREDITS.md) и [подробной атрибуции предыдущей пробы](../male-leg-human-trial/CREDITS.md). Точные SHA проверяемой страницы сохранены в отчётах.

# Отдельная проба сгиба пальцев модели А

[Результат, сравнения и инструкция для просмотра](../../work/character-model-search/selected-a/fist-refinement-trial/) — отдельный вариант [предыдущей пробы кистей и ушей](../../work/character-model-search/selected-a/hand-ear-study/), без перезаписи прежних файлов. Это эксперимент: большая петля мизинца стала меньше, но округлый сгиб и неплотный хват с некоторых ракурсов остаются. Качество формы требует визуальной оценки, а не только геометрических тестов.

## Как устроена проба

- Входной `female_A_hands_ears.glb` проверяется по SHA-256 `443a06634ec5d6d8dcee27f956022b511fc7012b4c3323e1320f15ec90d74707`. Сборщик меняет только четыре пары POSITION/NORMAL морфов кистей и метку генератора. Нейтральная геометрия, включая одобренные уши и открытые руки, и другие данные в буферах сохраняются; позиции/нормали/UV, лицо, веки, материалы, изображения, узлы и существующие клипы проверяются относительно предыдущей модели.
- Как и раньше, временные веса и суставы извлекаются из `work/character-showcase/prototype/assets/models/female_fixed.glb` с SHA-256 `bbde88441ee4f32f640e5a5a0d81b06989328ee5afede2732c42c4e5ef8ff158`; совпадение первых 14 517 UV проверяет предыдущий сборщик. Позиции в новой модели остаются позициями модели А. Скелет не переносится.
- `deform.py` вычисляет симметричный сгиб мизинцев по гладкой центральной линии с локальной коррекцией внутренней части сгиба. Для безымянного пальца смешана прежняя деформация с другой гладкой кривой, затухающей у корня. Указательные, средние и большие пальцы наследуют ранее подготовленную схему. Это корректирующие формы для конкретной сетки, не анатомический риг и не симуляция ткани.
- Пересчитаны формы на 0%, 25%, 50%, 75% и 100%, включая нормали. `Fists` хранит конечный сгиб, три оставшиеся цели — корректировки для промежуточных форм. Между ними путь кусочно-линейный по вершинам. Для ручного изменения используются все четыре веса по формулам из пользовательского README; один морф `Fists` не даёт показанный путь. У `Fists_Close` и `Fists_Open` по девять ключей в течение 0,35 с. `Blink_Once` и цели лица/век не изменены.
- Витрина содержит прежний процедурный колодец и свет; меняются только подписи пробы и встроенная модель. Отдельного GLB колодца в ZIP нет. Волосы не добавлены. Внешние фотографии, модели и код из исследовательских справочных материалов в поставку не включены.

## Сборка и проверки

Из корня репозитория; необходимы Python 3.11, Node.js, `unzip` для браузерных проверок и исходные файлы по путям в сборщике. После установки зависимостей сеть не требуется. `python-fcl` нужен только для проверки пересечений. Chromium может потребовать системные библиотеки; при необходимости можно задать `CHROME_BIN`.

```bash
python3 -m venv /tmp/bow-fist-venv
. /tmp/bow-fist-venv/bin/activate
pip install -r tools/model-a-hand-ear/requirements.txt
npm ci --prefix tools/character-showcase
npm ci --prefix tools/model-a-motion
python tools/model-a-fist-trial/build.py
python tools/model-a-fist-trial/qa.py --rebuild
python tools/model-a-fist-trial/qa-geometry.py --samples 201
node tools/model-a-fist-trial/qa-gltf.mjs
node tools/model-a-fist-trial/qa-offline.mjs
PYTHON=python node tools/model-a-fist-trial/qa-browser.mjs
PYTHON=python node tools/model-a-fist-trial/review.mjs
```

Сборщик принимает `--source`, `--rig`, `--well-archive`, `--output` и отказывается писать в каталоги обеих предыдущих проб. Структурный тест принимает `--source`, `--result`, `--well-archive`; геометрический — `--result`, `--rig`, `--samples`. glTF-, браузерный и снимочный тесты принимают позиционный путь к каталогу результата. Браузерный тест временно копирует GLB и ZIP под старыми именами и запускает прежний `qa-browser.mjs`, который сравнивает освещение, колодец, открытые кисти и лицо также с более ранней `motion-study`. Снимочный тест отдельно сравнивает именно `hand-ear-study` с новой пробой. На программном WebGL браузерные проверки могут занимать несколько минут. `review.py` лишь кадрирует, масштабирует для серии стадий, подписывает и соединяет настоящие снимки; виды изнутри изолируют кисть только при рендере.

### Результаты и ограничения

- Структурная проверка подтверждает неизменность нейтральной сетки и остальных данных буферов, совпадение остальной метаинформации GLB (кроме метки генератора и границ изменённых морфов), локальность всех четырёх морфов, зеркальность позиций и нормалей обеих кистей и совпадение позиций по геометрически сваренным UV-швам. Максимальное отличие конечного морфа от предыдущего — 26,42 мм. ZIP содержит точную копию GLB, автономную витрину, инструкцию и лицензию. Повторная сборка GLB и ZIP в той же среде дала побайтово идентичные результаты.
- Khronos glTF Validator: **0 ошибок, 0 предупреждений, 0 информационных сообщений** и для предыдущей модели, и для новой.
- Автономная витрина проверена без внешних запросов: реальные GLB-клипы проиграны через `AnimationMixer`, проверены возврат, флажок и промежуточные веса, независимое моргание, ракурсы, мышь, сенсорное управление, экраны 390×844 и 320×568 и предпочтение уменьшенного движения. Свет и колодец сверены с более ранней `motion-study`; её открытые кисти и центральное лицо совпали с новой пробой попиксельно, как и возврат после моргания и сгиба. Отдельная снимочная проверка подтвердила попиксельное совпадение открытых кистей именно с предыдущей `hand-ear-study`. Дополнительно HTML открылся из `file://` без сервера, сети, отключения web-безопасности или специального разрешения доступа к файлам; 75% сгиба проверены.
- Выборочная FCL-проверка: **201 дискретный вес 0…1 на каждой руке**, 3 247 выбранных треугольников каждой кисти и 1 170/1 171 треугольников соответствующей ноги. Пары с общей сваренной вершиной исключены. Новых самопересечений среди выбранных треугольников кистей и контактов с выбранными треугольниками одноимённой ноги не обнаружено. Это не проверка всей сетки, противоположной ноги или непрерывного времени.
- В неизменённой открытой позе уже есть по пять не соседних контактирующих пар на каждой кисти. Они исключены из счёта *новых* контактов и отдельно отслеживаются: последние наблюдались на весе 0,095. Наибольший измеренный рост сообщённой FCL глубины существующего контакта — 2,892 → 3,878 мм при весе 0,015, тогда как вычисленная длина линии пересечения той же пары уменьшилась с 0,760 до 0,319 мм. Максимальный рост длины линии для другой исходной пары — 0,685 → 0,783 мм при весе 0,045. Эти величины не равнозначны объёмному проникновению и не доказывают отсутствие других проблем.

- GLB: **3 890 500 байт**, SHA-256 `d09710c1232708cfbbcba9054de3f928bece523f39a1c10e2605552f3e976539`.
- ZIP: **3 505 252 байта**, SHA-256 `0cebcf9f80dd31ff3c838bb3a2062bda33014d39453bb8929d621f8b35a4dfdc`.

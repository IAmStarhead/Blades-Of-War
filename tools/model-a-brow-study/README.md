# Ева А — проба дополнительного опускания рисунка бровей

[Результат и сравнение](../../work/character-model-search/selected-a/brow-study/) основаны на [последней пробе кистей](../../work/character-model-search/selected-a/fist-refinement-trial/). Предыдущие файлы остаются нетронутыми. Изменяется только рисунок бровей на существующей текстуре кожи; рельеф лица, геометрия, уши, моргание и все формы кистей не переделываются.

## Метод

- Сборщик проверяет входной GLB по SHA-256 `d09710c1232708cfbbcba9054de3f928bece523f39a1c10e2605552f3e976539` и восстанавливает одобренный рисунок бровей тем же алгоритмом, что `tools/model-a-motion/build.py`. Затем смещает его ещё на **1,25 пикселя** по U относительно предыдущего положения (итого 2,50 пикселя относительно положения до той правки). Эта координата на данном UV-острове направлена вниз по лицу. При проверке медианный вертикальный масштаб составил −1,41 мм на пиксель, то есть дополнительный сдвиг на поверхности приблизительно 1–2 мм; фактический вид зависит от ракурса и освещения.
- Меняются **683 текселя** существующего RGB PNG 1024×1024, только в x=835…846, y=467…591. До записи сборщик сверяет затрагиваемые пиксели с ожидаемым прежним рисунком. Остальная текстура остаётся попиксельно прежней. Никакие вершинные позиции, нормали, UV, материалы, морфы или каналы анимации не изменяются. Из-за другого размера PNG допустимо изменяются лишь длина его bufferView, смещения последующих bufferView, длина буфера и строка генератора GLB.
- Витрина берёт тот же шаблон и проверенный bundle колодца, меняя название пробы и встроенный GLB. Модель не содержит скелета: это не риг и не анимация рукопашного боя. Предыдущая проба кистей всё ещё имеет округлый сгиб и ранее описанные исходные контакты в открытой позе. Волосы не добавляются.

## Сборка и проверки

Из корня репозитория. Требуются Python 3.11, Node.js, `unzip` для браузерной проверки, исходные материалы по путям в сборщике; после установки зависимостей сеть не нужна. Chromium может требовать системные библиотеки; при необходимости задайте `CHROME_BIN`.

```bash
python3 -m venv /tmp/bow-brow-venv
. /tmp/bow-brow-venv/bin/activate
pip install -r tools/model-a-hand-ear/requirements.txt
npm ci --prefix tools/character-showcase
python tools/model-a-brow-study/build.py
python tools/model-a-brow-study/qa.py --rebuild
node tools/model-a-brow-study/qa-gltf.mjs
PYTHON=python node tools/model-a-brow-study/review.mjs
```

Сборщик принимает `--source`, `--well-archive`, `--output` и не записывает результат в каталоги четырёх предыдущих проб. `qa.py` принимает `--source`, `--result`, `--well-archive`; браузерная и glTF-проверки — позиционный путь к каталогу результата. На программном WebGL браузерная проверка может занять несколько минут. `review.py` только кадрирует и подписывает реальные снимки; геометрия при съёмке не изолируется и не изменяется.

### Выполненные проверки

- `qa.py --rebuild` сверяет всю метаинформацию GLB с исключением описанных выше служебных полей и сравнивает все bufferView, кроме PNG кожи, побайтово. Проверены оба участка бровей, отсутствие изменений вне них, направление смещения по UV и точное содержимое ZIP. Повторная сборка в той же среде дала побайтово идентичные GLB и ZIP.
- Khronos glTF Validator: **0 ошибок, 0 предупреждений, 0 информационных сообщений** и в исходной, и в новой модели.
- Оба HTML-файла открыты автономно через `file://`, без внешних запросов, отключения web-безопасности или специального разрешения доступа к файлам. Проверены имена клипов, флажок кулаков, 25% на ползунке, возврат к открытой позе и кнопка моргания при сжатых кистях; также проверены совместные промежуточные веса моргания и сгиба. Для короткого моргания при программном WebGL тест временно уменьшает разрешение рендера, затем восстанавливает его перед снимками. В фронтальном ракурсе изменились только пиксели вокруг бровей, а фиксированный снимок прежней сжатой кисти совпал попиксельно. Результаты [предыдущей выборочной проверки геометрии кистей](../model-a-fist-trial/README.md) применимы к неизменённой геометрии, но не доказывают отсутствие всех пересечений.

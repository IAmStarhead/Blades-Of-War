# Женские варианты на основе Евы

[Результаты, отдельные GLB, сравнительные кадры и автономная витрина](../../work/character-model-search/women-variants/) — предварительные взрослые художественные пробы, не этнографические стандарты и не утверждённые модели. Ева остаётся базовой женщиной. Предыдущие пробы не перезаписываются.

## Метод

- Вход — отдельная [проба глаз Евы](../model-a-eye-study/), SHA-256 `69d3818596d67037445a87fcc89e6aeacccf035a97c218cf139d117444139d10`. Сборщик также проверяет хеш вспомогательной модели с весами и совпадение UV; этот вспомогательный скелет **не** экспортируется в результат.
- Лицевые и ягодичные изменения используют отдельные MakeHuman targets с закреплёнными SHA-256 в `targets/manifest.json` и уже имеющиеся в репозитории данные. Влияние ограничено выбранными областями лица и задней части таза. В центре ягодиц и при переходе к верхней части бедра есть затухание. Для северянки и японского мотива грудь локально изменена через разницу существующих форм `maxcup` и `averagecup`. У централки более мягкое уменьшение проекции задаётся плавным локальным полем; оно вычисляется также для подразделённых вершин.
- У границы грудной области деформация плавно затухает к вершинам с весами рук во вспомогательном риге. Позиции и нормали всех исходных вершин с весами рук сохранены, как и кисти и область ниже `y=0,835 м` в локальных координатах. Ягодичная форма может затрагивать верхний переход к бедру. Для target-изменений дополнительные вершины груди наследуют среднее смещение исходных концов своего ребра. Швы проверяются отдельно.
- У японского мотива скорректирована небольшая область век: верхняя линия переносится по барицентрической интерполяции и получает пересчитанные morph-формы моргания. В текстуре только существующие голубые пиксели радужки окрашены в тёмно-карий; зрачок и белок сохраняются. Другие пробы сохраняют исходные глаза. Брови, кожа и волосы не переработаны.
- Рост задаётся равномерным масштабом **всей** модели: 105%, 100% и 95% относительно Евы. Это не создание новых пропорций конечностей и не имитация иной мускулатуры. В GLB сохранены исходные морфы кистей и клипы; скелета, боевого рига и одежды нет. Витрина встроена в ZIP и работает без сети.

Файлы `target` — данные MakeHuman assets под CC0; см. [источники и оговорки](../../work/character-model-search/women-variants/RESEARCH.md). Они сохранены побайтово, включая исходные пробелы в заголовках, и сверяются с манифестом. Найденные фотографии не включены в модели.

## Сборка и проверки

Из корня репозитория; требуются Python 3.11, Node.js, `unzip` и исходные файлы проекта. После установки зависимостей сеть не нужна. Для браузерных тестов Chromium может требовать системные библиотеки; альтернативный бинарный файл задаётся через `CHROME_BIN`.

```bash
python3 -m venv /tmp/bow-women-venv
. /tmp/bow-women-venv/bin/activate
pip install -r tools/model-a-hand-ear/requirements.txt
npm ci --prefix tools/character-showcase
python tools/women-variants/build.py
python tools/women-variants/qa.py --rebuild
node tools/women-variants/qa-gltf.mjs
python tools/women-variants/qa-geometry.py
PYTHON=python node tools/women-variants/review.mjs
node tools/women-variants/qa-mobile.mjs
```

`build.py` принимает `--source`, `--reference`, `--well-archive`, `--output`, `--models-only`; он проверяет хеши входов и отказывается писать поверх известных предыдущих проб и входных файлов. `qa.py` и `qa-geometry.py` принимают `--result` и пути к входам; геометрическая проверка также принимает `--samples`. Для Node-скриптов можно передать путь к каталогу результата позиционным аргументом. В программном WebGL браузерные проверки могут занимать несколько минут. `review.py` только кадрирует и подписывает реальные снимки; геометрия на кадрах не дорисовывается.

### Что проверено

- `qa.py --rebuild`: одинаковая метаинформация и bufferView за исключением задокументированных изменений, равномерный масштаб, сохранение кистей, защищённых вершин и нижней области, целостность совпадающих швов, отсутствие перевёрнутых или сильно сжатых исходно невырожденных треугольников, положение окрашенных текселей и ширина линии век на 11 значениях моргания. Для централки дополнительно ограничен угол изменения нормалей выбранных граней передней поверхности груди (не более 25°); это регрессионный критерий, не замена визуальному просмотру. GLB и ZIP в указанной среде пересобраны побайтово идентично. Максимальное смещение локальных вершин: 19,64 мм у северянки, 10,03 мм у централки, 18,41 мм у восточной пробы.
- Khronos glTF Validator: **0 ошибок, 0 предупреждений, 0 информационных сообщений** у Евы и трёх вариантов.
- FCL: в выбранных областях исходно обнаружено 0 пар контактов на лице, 86 на груди и 11 в зоне ягодиц; у вариантов новых выбранных пар нет. Максимальное увеличение глубины исходных выбранных контактов груди — 0,011 мм. Сравнение кистей и области ягодиц проведено для девяти дискретных положений сжатия обеих кистей; новых выбранных пар не найдено. Это **не** проверка всей сетки или непрерывного движения; исходные локальные пересечения у основания больших пальцев остаются.
- В автономном браузере проверены выбор персонажа, ракурсы с учётом масштаба, моргание, кулаки, сохранение их весов при переключении и кадры моделей. `qa-mobile.mjs` проверяет мобильную ширину, ползунок и быстрое переключение. Витрина предназначена для предварительного просмотра, а не заменяет тест импорта в игровой движок.

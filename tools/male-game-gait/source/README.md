# Source asset for the separate gait trial

`character.glb` is the converted **Animated Human** by Quaternius, downloaded from <https://github.com/dfayd0/n3d2/blob/9f2ccc2770d69a49b63e5d5184a1206cf547ef76/assets/models/character.glb>. The mirror identifies it as Quaternius Animated Human, CC0, and says it was converted from FBX to glTF. SHA-256: `ce4d543e82e455d5a1253798c9759f12b9eec74929ddbca464447eeaa3a42c5d`.

The creator's 2017 listing <https://opengameart.org/content/animated-human-low-poly> explicitly states CC0 and lists walk and run. The converted mirror has not been byte-compared with the original download archive. `LICENSE_CC0.txt` is the CC0 1.0 legal text. The 2017 pack is separate from Quaternius's Universal Animation Library (2025), which was tried previously.

## Изменения и источники

- Входной GLB проверяется по SHA-256 `5df2138963662f7630cd9674ccd8111d4bb415b270424401c4915f97e0810eac`. От двух существующих лент века сохраняются 61 из 73 рядов на каждую сторону: 12 рядов выступающих стрелок удалены, шесть крайних рядов плавно сужены и повторно спроецированы на прежнюю поверхность века/глаза. Отдельных ресниц нет. Объект переименован в `upper_eyelid_line`.
- На оригинальные 14 517 вершин тела применяется `0.42 × (maxcup-maxfirmness − averagecup-maxfirmness)` — разница двух CC0-целей MakeHuman, по сохранённой таблице соответствия вершин из предыдущего инструмента. Единицы target переводятся из дециметров в метры коэффициентом `0.1`. Двигаются 406 вершин в области груди, максимальное смещение — около 34,36 мм. Нормали корректируются только в соседстве изменённых граней.
- Для менее угловатого контура в затронутых треугольниках локально добавлены 1 349 вершин: средние точки внутренних рёбер слегка изгибаются по нормалям, на границе остаются точно на исходных рёбрах. Соседние грани при необходимости тоже делятся, чтобы избежать T-образных разрывов; их поверхность вне затронутых граней не смещается. UV новых точек интерполированы по рёбрам, исходные UV не меняются. У прежних UV-швов совпадающие координаты остаются совпадающими.
- Голубые глаза и обе текстуры — побайтово прежние. Брови, нос, уши, ягодицы и остальные исходные позиции тела не перерабатываются. Добавление волос не выполнялось; [исследование для следующего этапа](../../work/character-model-search/selected-a/refined-v2/HAIR_RESEARCH.md) хранится отдельно.
- Новый target [`maxcup-maxfirmness`](https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/makehuman/data/targets/breast/female-young-averagemuscle-averageweight-maxcup-maxfirmness.target) — байтовая копия MakeHuman из коммита `a8bc2d54ff0ac92e78ff71431b1023eda42bf482`, Git blob `b23e0c8827c28652890956171c964af7323739e0`, SHA-256 `76737472bf148e69bd5e80da982b88aa0926b51ef9ea1ac6217da88d86cf55cf`. Второй target и подтверждённое UV-сопоставление находятся в `tools/model-a-refinement/makehuman/`; их SHA-256 также проверяются при сборке. Ассеты MakeHuman выпущены под CC0 1.0, полный текст включён в ZIP; лицензирование и происхождение исходной А описаны в [предыдущем инструменте](../model-a-refinement/README.md).
- HTML новой витрины **в точности совпадает** с предыдущей витриной, кроме встроенного женского GLB. Код и материалы подробного процедурного колодца скопированы из исходного `BladesOfWar_Adam_Eve_Showcase (3).zip` без изменений. Мужской модели в этой витрине нет. Отдельный GLB колодца не создавался.

## Сборка и проверка

Требуется Python 3.11, NumPy и Pillow из уже существующего файла зависимостей, а для браузерной и glTF-проверок — Node.js и зависимости существующего инструмента витрины:

```bash
python3 -m venv tools/model-a-revision/.venv
. tools/model-a-revision/.venv/bin/activate
pip install -r tools/model-a-refinement/requirements.txt
python tools/model-a-revision/build.py
python tools/model-a-revision/qa.py
npm ci --prefix tools/character-showcase
node tools/model-a-revision/qa-gltf.mjs
node tools/model-a-revision/qa-browser.mjs
# При необходимости пересоздать PNG-сравнения тем же браузерным рендером:
node tools/model-a-revision/qa-browser.mjs --shots
```

Сборка автономна, проверяет SHA исходного GLB, обоих targets, таблицы вершин и исходного архива колодца. Есть параметры `--source`, `--well-archive`, `--output`; тесты принимают `--result`, а `qa.py` также `--source` и `--well-archive`. Для браузерной проверки можно указать `CHROME_BIN`; Chromium может потребовать системные библиотеки. Снимки «до/после» берутся из одного HTML с одинаковой камерой и светом; изменяется только встроенный GLB, затем производится одинаковая обрезка и добавляются подписи. Тени могут слегка отличаться на другом GPU.

`qa.py` проверяет побайтовую неизменность глаз и текстур, локальность исходных вершин и нормалей, UV-интерполяцию, сохранение поверхности соседних неизменённых граней, швы, замкнутость сваренной сетки, ориентацию и отсутствие вырожденных треугольников, две связные линии век, отсутствие стрелок и отдельных волосков. Также сравнивает ZIP и HTML с предыдущей витриной, проверяет оригинальный код колодца и отсутствие мужского GLB. glTF Validator проверяет обе версии. Браузерный тест работает без сети, проверяет режимы/ракурсы и управление мышью, затем экраны 390×844 и 320×568.

- ZIP 2 603 675 байт, SHA-256 `49f54081ab5d600e73e029baecc67d9dbae8fcc7a51edb2935af0fde521e8056`.
- 1 122 группы совпадающих швов сохранены; разрывов, вырождений и перевёрнутых граней не обнаружено. Khronos glTF Validator: 0 ошибок, 0 предупреждений, 0 информационных сообщений для обеих версий.

Модель статична: скелета, анимаций и морфов нет. Автоматическое моргание и движение будущих волос потребуют отдельной работы.

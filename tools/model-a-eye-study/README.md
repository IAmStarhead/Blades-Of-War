## Метод

- Вход — `female_A_brows_lower.glb`, SHA-256 `87db24775e0ab3f82e0511ebed8077ae443cabf8b3aa75003fbccd79e0dcd356`. Голубые участки действительно присутствуют в RGB-карте глаз, а не являются эффектом света. Для их восстановления взята карта из уже имеющегося `work/character-showcase/prototype/assets/models/female_fixed.glb`, SHA-256 `bbde88441ee4f32f640e5a5a0d81b06989328ee5afede2732c42c4e5ef8ff158`. Сборщик сверяет совпадение всех 96 глазных UV. На неповреждённом белке старая карта сопоставлена по каналам с текущим тоном; заменяются только заметно голубые участки вне радиуса радужек. Цветовой рисунок белка сохраняется, а не закрашивается плоским белым.
- В текстуре 1024×1024 изменено **92 815 пикселей** на двух глазных островах; значительная часть расположена за пределами видимого сквозь веки участка. Все пиксели в пределах 132 texels от центров радужек и вне глазных зон побайтово неизменны. Голубая радужка, зрачки, глаза как геометрия, материалы и текстура кожи не заменяются.
- Верхняя линия слегка расширена, сглажена и сужена у внутреннего конца без добавления стрелок. Она следует прежней непрерывной ленте; сдвиг любой её вершины не превышает **0,967 мм**. Пересчитаны лишь два морфа линии, чтобы она следовала существующему морганию и сужалась при закрытии. Другие вершины, нормали и все остальные морфы и клипы сохранены.
- Данные MakeHuman/MPFB2 assets — CC0 1.0 Universal; лицензия включена в ZIP. Фотографии из веб-поиска в результат не копировались.

## Сборка и проверки

Python 3.11; зависимости — `tools/model-a-hand-ear/requirements.txt`, Node-зависимости — `tools/character-showcase`. После их установки сеть не нужна. Chromium может требовать системные библиотеки; можно задать `CHROME_BIN`.

```bash
python tools/model-a-eye-study/build.py
python tools/model-a-eye-study/qa.py --rebuild
node tools/model-a-eye-study/qa-gltf.mjs
PYTHON=python node tools/model-a-eye-study/review.mjs
```

`build.py` принимает `--source`, `--reference`, `--well-archive`, `--output` и не записывает результат поверх входов или предыдущих изучаемых версий. `qa.py` проверяет метаданные, побайтовую неизменность всех bufferView кроме PNG глаза, ленты и двух её морфов, расположение изменённых текселей, отсутствие выворачивания рядов при 11 значениях моргания, ZIP и повторную сборку. Сравнение PNG использует те же реальные ракурсы, без дорисовки; отдельный фрагмент белка увеличен в пять раз методом ближайшего соседа.

Выполнено: **0 ошибок и предупреждений** Khronos glTF Validator для источника и результата. Оба HTML открыты с `file://` без сети и без отключения безопасности браузера; у новой модели проверены флажок и 25% ползунка кулаков, возврат к открытым кистям и независимое моргание. На фиксированном полном лице изменено 315 пикселей, все в области глаз; фиксированный ракурс кисти попиксельно совпадает. Для наблюдения короткого моргания на программном WebGL тест временно снижает pixel ratio, затем восстанавливает его для снимков. Проверка 11 дискретных положений не является доказательством отсутствия любых артефактов во всех ракурсах и движках.

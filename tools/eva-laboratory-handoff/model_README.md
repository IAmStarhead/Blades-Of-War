# Модель героини: проба для отдельной игры

В этой папке — **две версии одной и той же основы**:

- [`female_A_ears_refined.glb`](female_A_ears_refined.glb) — последняя проба со смягчённым контуром ушей. Это вариант для оценки, не утверждённый окончательный облик.
- [`female_A_eyes_refined.glb`](female_A_eyes_refined.glb) — сохранённая исходная версия до этой правки ушей. Её геометрия, текстуры и клипы не заменялись.

Обе модели без одежды и волос. В них **нет скелета, боевого рига, ходьбы или других полноценных игровых анимаций**. Есть моргание и предварительный симметричный морф сжатия кистей. Форма хвата местами неплотная, а исходная открытая сетка имеет локальные самопересечения у оснований больших пальцев. Для игры потребуются риг и отдельная проверка деформаций. Файлов `.blend` и `.fbx` в комплекте нет; GLB можно импортировать в 3D-редактор, поддерживающий glTF.

## Как посмотреть

Откройте [`Heroine_Showcase.html`](Heroine_Showcase.html) в браузере с WebGL. Он автономный: интернет и установка программ не нужны. Это **просмотр последней пробы**, её GLB уже встроен в HTML. На GitHub HTML отображается как код; для интерактивного просмотра скачайте проект и откройте файл на своём устройстве.

Кнопки «Левое ухо» и «Правое ухо» переключают ракурсы; мышь вращает сцену и колесо меняет масштаб, на телефоне можно использовать пальцы. Есть моргание и ползунок сжатия кистей. Доступный в витрине колодец — старый объект для просмотра модели, **не игровой уровень и не утверждённый элемент этой игры**; отдельного файла GLB колодца здесь нет.

## Технические сведения и ограничения

В каждой версии **35 686 треугольников**, три материала и две встроенные текстуры 1024×1024. Размер GLB около 3,85 МБ не равен потреблению видеопамяти. Глаза, лицо, остальное тело, топология, материалы и существующие морфы от исходной версии не менялись; при правке перемещены только вершины ушей и их соединения с головой. Встроены клипы `Blink_Once`, `Fists_Close` и `Fists_Open`.

Для промежуточного значения сгиба кистей `f` от 0 до 1 используйте клипы или все четыре веса одновременно:

```text
basemesh_female_body.Fists                      = f
basemesh_female_body.FistQuarterCorrection      = max(0, 1 - abs(f - 0.25) / 0.25)
basemesh_female_body.FistHalfCorrection         = max(0, 1 - abs(f - 0.50) / 0.25)
basemesh_female_body.FistThreeQuarterCorrection = max(0, 1 - abs(f - 0.75) / 0.25)
```

Для моргания: `face_blink.Blink = b`, `upper_eyelid_line.Blink = b`, `upper_eyelid_line.BlinkLineNarrow = min(1, 2*b)` при `b` от 0 до 1. Это морфы, а не независимый риг пальцев или век; воспроизведение и удержание позы зависят от импортёра и кода игры.

Khronos glTF Validator ранее показал 0 ошибок и предупреждений для обеих моделей. Проверены локальность правки, сваренные швы, выбранные локальные контакты, работа моргания и кулаков в витрине; **выборочные проверки не гарантируют отсутствие проблем во всех позах и игровых движках**. Производительность на целевом ноутбуке не измерялась.

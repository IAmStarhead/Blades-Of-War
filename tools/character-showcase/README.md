# Витрина персонажей: сборка и проверки

Исправленная витрина и отдельные GLB находятся в `work/character-showcase/prototype/`. Готовый архив создаётся рядом: `work/character-showcase/BladesOfWar_Adam_Eve_Showcase_Repaired.zip`. Исходный `BladesOfWar_Adam_Eve_Showcase (3).zip` не перезаписывается.

## Воспроизведение

Скрипт рассчитан на конкретный исходный архив; его SHA-256 проверяется до сборки. Нужны Python с NumPy, SciPy и Pillow, а для браузерных проверок — Node.js 22 и Chromium.

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r tools/character-showcase/requirements-qa.txt
npm ci --prefix tools/character-showcase

python tools/character-showcase/build.py
python tools/character-showcase/package.py
```

`build.py --input ПУТЬ --output ПАПКА` позволяет указать другое расположение **того же** исходного архива и папку результата. Скрипт извлекает три ожидаемых файла во временную папку, пересобирает оба GLB и вставляет в HTML точно те же байты. Архиватор проверяет соответствие встроенных и внешних моделей и целостность ZIP.

Откройте `BladesOfWar_Showcase.html` из папки результата в браузере с WebGL. Зависимость от сети отсутствует. При необходимости можно раздать папку локальным HTTP-сервером, но установка npm не требуется для просмотра готовой витрины. Ракурсы автоматически кадрируют выбранные объекты; после ручного вращения или масштабирования изменение размера окна не сбрасывает камеру. В общей сцене «Профиль» использует ракурс три четверти, чтобы обе модели оставались видны. Кнопка крупного плана колодца в одиночном режиме переключает на сам колодец.

## Регрессионные проверки

```bash
node tools/character-showcase/qa-gltf.mjs
python tools/character-showcase/qa-static.py
node tools/character-showcase/qa-browser.mjs --capture /tmp/bow-showcase-poses.json
python tools/character-showcase/qa-geometry.py --poses /tmp/bow-showcase-poses.json
```

`qa-browser.mjs` использует установленный `@sparticuz/chromium`; если нужен системный браузер, задайте `CHROME_BIN=/путь/к/chromium`. На Linux должны быть установлены системные библиотеки, необходимые выбранному Chromium. Дополнительный параметр `--shots ПАПКА` сохраняет контрольные снимки. Большой файл с позированными вершинами в `/tmp` — временный и не нужен пользователю витрины.

FCL проверяет лишь выбранные по весам кожи группы треугольников в статичных позах. Отсутствие обнаруженных контактов не доказывает отсутствие всех возможных пересечений и не оценивает качество отсутствующих в исходнике клипов ходьбы и бега. Кулаки остаются несколько разжатыми; для плотного естественного сжатия потребуется ручная доводка рига и корректирующих форм.

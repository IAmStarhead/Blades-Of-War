# Проба мягкой кожи и освещения модели А

Результат, реальные снимки и инструкция для пользователя: [`work/character-model-search/selected-a/relief-study/`](../../work/character-model-search/selected-a/relief-study/). Это отдельная проба поверх [утверждённой модели А версии 2](../../work/character-model-search/selected-a/refined-v2/), не перезапись исходников. Причёска пока не согласована и не добавляется.

## Изменения и границы

- Входной GLB проверяется по SHA-256 `ce7e25dc4e4160595dd2d1e14bd68a8ea008eef7ae80d0db687a4d6c8002004c`. Пересоздаётся только PNG существующей 1024 × 1024 карты цвета кожи. Низкочастотные вариации цвета вычисляются по 3D-координатам и наносятся на UV без внешних фотографий, рисованных направленных теней, пор или высокочастотного шума. Сильные существующие детали и область бровей защищены; область глаз дополнительно защищена в 3D, чтобы разные стороны UV-шва не получили заметно отличающийся цвет.
- Все остальные бинарные блоки **побайтово идентичны** источнику: позиции, нормали, UV, индексы, сетки глаз и линий век, изображение голубых глаз. Материалы и их параметры не меняются, нет новых карт или моделей. Всего 31 066 треугольников, как в v2; нет скелета, анимаций или morph targets.
- Кожа слабо меняется в каналах RGB (не более −5…+3 из 255). Старый PNG занимал 31 583 байта, новый — 82 526 байт; декодированный размер тот же. Новый GLB на 50 944 байта больше оригинала. Это рост сжатых данных, не новые текстуры или полигоны; в зависимости от движка оперативная/видеопамять определяется декодированным форматом текстуры, который по размеру здесь не меняется.
- Только в режиме **«Женщина А»** автономной витрины можно включать/отключать предложенный баланс существующих источников. В режиме «Колодец» и «Вместе» автоматически возвращается прежний свет; выбор флажка запоминается при переключении режимов. Источников света не добавлено, существующая 1024² shadow map и настройки cast/receive не меняются. Дополнительных теневых проходов этот вариант не вводит. Мягкость здесь означает умеренный баланс освещения, а не новую размытую карту теней.
- Код и материалы колодца берутся без изменений из `BladesOfWar_Adam_Eve_Showcase (3).zip`; SHA-256 исходного архива проверяется прежним построителем. HTML построен на прежнем шаблоне, к нему добавлен переключатель света. В парной сцене освещение то же, что раньше. В ZIP нет мужской модели; колодец создаётся процедурно, отдельного GLB колодца нет.
- В самом GLB освещение не записано. При импорте в другой просмотрщик или игру остаётся только изменение цвета кожи; свет и его стоимость зависят от конкретного движка и сцены. Для выполнения данной пробы дополнительные динамические self-shadows не включали: в тесте прежней сцены они практически не изменили изображение.

## Сборка и проверки

Требуется Python 3.11, NumPy и Pillow из существующего файла зависимостей; браузерным тестам также нужны Node.js и зависимости прежнего инструмента:

```bash
python3 -m venv tools/model-a-relief/.venv
. tools/model-a-relief/.venv/bin/activate
pip install -r tools/model-a-refinement/requirements.txt
python tools/model-a-relief/build.py
python tools/model-a-relief/qa.py
npm ci --prefix tools/character-showcase
node tools/model-a-relief/qa-gltf.mjs
node tools/model-a-relief/qa-browser.mjs
# Дополнительно переснять реальные сравнения из обеих автономных витрин:
node tools/model-a-relief/qa-browser.mjs --shots
```

Сборка работает без сети. Есть параметры `--source`, `--well-archive`, `--output`; тесты принимают `--result` (браузерный и glTF-тесты — позиционный путь), `qa.py` также принимает `--source` и `--well-archive`. Для браузера можно задать `CHROME_BIN`; Chromium может потребовать системные библиотеки. На программном WebGL пересъёмка занимает несколько минут.

`qa.py` проверяет структуру GLB, побайтовое совпадение всех блоков кроме PNG кожи, неизменность материалов, текстуры глаз и бровей, допустимую силу изменения цвета и выборки у совпадающих вершин UV-швов. Также проверяет ZIP, прежние исходники, код колодца, лицензию и отсутствие мужского GLB. Khronos glTF Validator проверяет обе модели. Браузерный тест открывает витрины без сети, проверяет переключатель света и исходные настройки в режимах колодца/общей сцены, управление мышью и касаниями, три режима × четыре ракурса, отдельный ракурс лица и экраны 390×844 и 320×568. Проверяет четыре попиксельных снимка колодца против версии 2: отдельно и в общей сцене с временно скрытой Евой, по два ракурса.

При `--shots` камера у каждой пары совпадает. Основные снимки показывают одновременно новую кожу и свет; отдельные пары показывают только кожу при одном и том же свете или только свет на одной и той же новой модели. `review.py` только одинаково обрезает снимки и добавляет подписи. Внешний вид может немного отличаться в другом браузере, движке или GPU.

Проверено при Python 3.11.2 / NumPy 2.4.6 / Pillow 13.0.0 / zlib 1.2.13:

- GLB: 1 554 208 байт, SHA-256 `9d79a868a388f07443968e334da7f6b0b2be0f7515824f7b0535549eae11b425`.
- ZIP: 2 712 626 байт, SHA-256 `691857f467e476e45d9bd33c85fc2d9d005ea644dba3a38b8b66f317d97d06a6`.
- Повторная сборка дала побайтово те же GLB и ZIP; валидатор: 0 ошибок, 0 предупреждений, 0 сообщений для обеих моделей. У 1 122 групп совпадающих вершин швов максимальное различие **самого изменения цвета**, вычисленное билинейной выборкой в этих вершинах, — 1 уровень из 255.

# Отдельная проба ожидания и остановки

**[Открыть сцену](index.html)** · **[Видео и сравнение](study.html)** · **[Прежняя проба](../male-stealth-posture-trial/index.html)**

Здесь присед **временно отключён**: кнопки и действия по C нет. Прежняя сцена с приседом сохранена без изменений. На текущем мужском персонаже добавлены более живое ожидание и отдельные торможения после ходьбы и бега. Это рабочая проба, а не окончательное утверждение качества анимации.

`index.html` содержит модель и код и открывается без сети в браузере с WebGL. Для страницы сравнения нужны соседние файлы, а для ссылки на прежнюю пробу — соседняя папка `male-stealth-posture-trial`. Если в системе включено уменьшение движения, цикл ожидания останавливается; ходьба и управление остаются доступными.

## Управление

- **WASD / стрелки** или нажатие на землю — двигаться. **Shift** во время движения — бег; для маршрута по нажатию используйте кнопку темпа «Ходьба / Бег».
- Отпустите клавиши, нажмите **«Стоп» / Esc** или дойдите до цели, чтобы увидеть торможение. Начните движение снова во время торможения, чтобы прервать его.
- Потяните сцену или нажмите **↶ / ↷**, чтобы повернуть камеру. **− / V** — общий план; **+ / V** — крупный план.
- **E / «Осмотреть»** или нажатие на колодец — подойти и осмотреть его; это только проба жеста, не добыча воды.

## Что изменено

Ожидание основано на CC0-движении из HumanMotionCraft: перенесено на текущий риг, дополнено небольшим дыханием и замкнуто в цикл около 5,9 секунды. В прежней сцене тоже было небольшое авторское дыхание — она не являлась буквально неподвижной. Два разных торможения адаптированы из движений, **созданных Kimodo**, а не записанных motion capture. Обе стороны и несколько начальных фаз выбираются по положению ног; скорость плавно снижается по рассчитанной кривой, поза смешивается с ожидающей. Торможение можно прервать. Движения ходьбы и бега в GLB не перезаписаны. Подробное происхождение, лицензии и сделанные изменения — в [CREDITS.md](CREDITS.md).

## Проверки и известные ограничения

- Записаны сравнения одинаковых команд: [ожидание на протяжении полного цикла, два ракурса](idle-comparison.mp4) и [ходьба, бег, остановка и возобновление, четыре ракурса](comparison.mp4). Я визуально просмотрел последовательности выборочных кадров спереди, сбоку, сзади и в три четверти, в том числе после бега; по отдельным кадрам нельзя надёжно оценить всю плавность. Видео позволяет Вам посмотреть движение непрерывно. Камера в записи следует за персонажем; отметки зафиксированы на земле и добавлены только для видео.
- Браузерные проверки offline и HTTP: 80 выбранных поз ходьбы/бега совпадают с прежней плоской походкой до численной погрешности; проверены 48 фаз торможения, 10 прерываний, развороты, маршруты, осмотр колодца, реальные клавиатурные и указательные события, касания на четырёх эмулированных размерах и живой цикл после касания. У страницы сравнения проверены ссылки, воспроизведение и перемотка двух видео. Физический телефон не проверен. Отчёты сцены: [offline](qa-offline.json), [HTTP](qa-http.json); сравнения: [offline](qa-study-offline.json), [HTTP](qa-study-http.json).
- На 16 прямолинейных остановках, 60 Гц, отслеживались вершины обеих стоп. Максимальное смещение одной вершины за эпизод у пола — примерно **0,134 м после ходьбы и 0,286 м после бега** (порог `y ≤ 0,012 м`, минимум шесть кадров; визуальная поверхность на `y = −0,002 м`). [Отчёт](foot-report.json). Близость к полу **не доказывает физического контакта**, а движение одной вершины не измеряет скольжение всей стопы. Ограниченная фиксация включается только ближе к концу остановки и в покое: **скольжение всё ещё возможно**, особенно в раннем переходе или при изменении направления.
- В 230 выборочных позах idle, остановок и прерываний не обнаружено пересечений выбранных областей кистей, стоп, коленей и таза ([отчёт](collision-report.json)). Это не проверка всей сетки, всех фаз, направлений и объектов окружения.

## Сборка и повторение

В полном репозитории нужны Node.js 22, npm и браузерные зависимости `tools/character-showcase`:

```sh
npm ci --prefix tools/character-showcase
npm ci --prefix tools/male-idle-stop-trial
npm run build --prefix tools/male-idle-stop-trial
npm test --prefix tools/male-idle-stop-trial
npm run check:study --prefix tools/male-idle-stop-trial
npm run check:contact --prefix tools/male-idle-stop-trial
```

Сборка проверяет SHA исходной модели и источников, пересоздаёт `tools/male-idle-stop-trial/clips.json` и пишет только `work/male-idle-stop-trial/index.html`. Для отдельной папки вне репозитория: `npm run build --prefix tools/male-idle-stop-trial -- --output /tmp/idle-build`; клипы в `tools/` всё равно пересоздаются. Для браузерных проверок нужен Chromium; при необходимости задайте `CHROME_BIN` и установите его системные библиотеки. `npm test` проверяет локальный файл без сети; для проверки работающего HTTP добавьте `-- http://127.0.0.1:4365/male-idle-stop-trial/index.html` к команде.

Запуск локального сервера с поддержкой перемотки видео: `PORT=4365 node tools/male-idle-stop-trial/serve.mjs`. На том же компьютере откройте `http://localhost:4365/`; в удалённой среде используйте ссылку её предпросмотра. Копия в `docs/male-idle-stop-trial/` подготовлена для публикации, но GitHub Pages необходимо отдельно включить в настройках репозитория. Сборка не обновляет копию в `docs/` автоматически.

Выборочная проверка областей требует NumPy и `python-fcl`:

```sh
node tools/male-idle-stop-trial/export-collision.mjs /tmp/idle-stop-poses.json
python3 tools/male-stealth-tuning/qa-collision.py /tmp/idle-stop-poses.json --report /tmp/idle-stop-collisions.json --strict
```

Для повторной записи нужны FFmpeg с `libx264` и `drawtext`, шрифт с кириллицей и Chromium. Скрипт не перезаписывает существующие файлы; при необходимости задайте `FFMPEG_BIN`, `FONT_FILE` и `CHROME_BIN`:

```sh
node tools/male-idle-stop-trial/record.mjs /tmp/stops.mp4
node tools/male-idle-stop-trial/record.mjs --idle /tmp/idle.mp4
```

Оба ролика используют фиксированный шаг симуляции 1/60 секунды и 30 кадров видео в секунду; это не тест производительности физического устройства. SHA проверяемого HTML указан в JSON-отчётах.

# Head integration experiment — not applied

These are browser captures of a discarded integration experiment, not the current playable characters. The test used a head derived from MakeHuman's CC0 base mesh and morph targets. Its neck intersected the existing body and the existing beard texture mapped incorrectly, so the experiment was reverted rather than replacing the working heads. Hair was hidden during the review.

Source: [MakeHuman assets and license](https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.ASSETS.md).

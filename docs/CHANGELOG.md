## 2026-11-05 — 0.0.3 «Разговор и облик» — правки по замечаниям владельца

**Сделано по пяти замечаниям после игры:**

1. **Затухание при смене сцены.** Экран гаснет и проявляется заново
   (`@keyframes bow-fade-in`, класс вешается при смене локации).
   Отключается при `prefers-reduced-motion`.
2. **Новая палитра.** Вместо охристо-бурой («мочевой») — холодный камень,
   серебро, воронёная сталь, бордо как королевский акцент, латунь дозированно.
   Все цвета заданы переменными в `:root`.
3. **Диалоги с выбором.** Отдельный модуль `065-dialog.twee`: дерево разговора
   в данных персонажа, 2–3 варианта ответа, влияние на отношение, значимые
   реплики попадают в журнал. Разговор переживает перерисовку интерфейса.
4. **Внешность и осмотр жителя.** У каждого персонажа пять параметров наружности
   (рост, телосложение, лицо, одежда, приметы). Кнопка «Осмотреть» открывает
   карточку. Это статичное описание, не симуляция внешности.
5. **Атмосфера отделена от хроники.** Бытовые зарисовки («кто-то сидит за столом»)
   теперь идут в блок атмосферы под описанием сцены и НЕ пишутся в журнал.
   В журнал попадают только события, слухи и значимые реплики.

**Дополнительно из ТЗ:**
- Погода по сезону (описательная, механического влияния пока нет — обозначено).
- Счётчик визитов в локации, первая встреча отмечается отдельно.
- Миграция сохранений 0.0.2 → 0.0.3: старые сохранения не теряются.

**Проверено:** `npm run check` — 50 из 50.
**Не проверено:** визуальный вид — Chromium в песочнице недоступен.

## 2026-11-05 — 0.0.2 «Фундамент» — первый играбельный прототип

**Сделано:**
- **Настоящая история SugarCube 2.37.3**, а не сайт-имитация. Сборка через `extwee`.
- Модульное ядро: 13 модулей в `src/js/`, ядро не знает про SugarCube и DOM.
- Кастомный интерфейс `StoryInterface`: три колонки → две → одна.
- Пять локаций тестового поселения, четыре NPC с характером и памятью.
- Торговля по локациям, еда, питьё, отдых, разговоры, окно персонажа.
- Время: час → день → месяц → год, сезоны, ночь.
- Причинные события: голод, истощение, ночь в тайге, слухи на площади.
- Сохранения: контрольная сумма, структурная проверка, миграции, автосейв,
  выгрузка и загрузка файла.
- 35 автоматических проверок в `tools/check.js`.

**Исправлены ошибки старого прототипа v0.0.1 (все 8 подтверждённых):**
1. Кнопка «Отдохнуть» — теперь настоящее действие.
2. Время больше не идёт вдвое быстрее: единая точка `Bow.time.advance()`.
3. Потребности падают по часам, а не по числу вызовов; границы 0..100 соблюдаются.
4. Пол персонажа берётся из данных (`pron`), «она» про Тарна невозможна.
5. Полувалидные сохранения отклоняются до применения — состояние не портится.
6. Деньги хранятся только в `player.money`, без дублирующего предмета-монеты.
7. Стартовые события и журнал создаются в состоянии, а не в копии.
8. Предметы не дублируются с одинаковым `id`; журнал ограничен по размеру.

**Проверено:**
- `npm run build` — сборка 700 КБ, внешних ссылок 0.
- `npm run check` — 35 из 35 проверок пройдено.
- Живой предпросмотр по HTTP — отдаётся корректный HTML, 200 OK.

**Не проверено:**
- Визуальное отображение и мобильная вёрстка в реальном браузере —
  Chromium в песочнице скачать не удалось.

**Технические находки (записаны, чтобы не наступить снова):**
- `StoryInit` не выполняется при ручном запуске без `Engine.runUserInit()`.
- Аргументы макросов-виджетов приходят **строками**, если это не переменная
  вида `$x`/`_x`. Объект в аргументе превращается в `"[object Object]"`.
- Макросы внутри HTML-атрибутов ломают парсер: `<<if>>` в теге даёт
  «child tag found outside of its parent macro». Динамические кнопки надо
  собирать строкой и выводить через `<<= >>`.
- Литерал `[...]` внутри аргументов виджета парсится как ссылка Twine.
- `extwee` не собирает каталог — файлы склеиваются скриптом.

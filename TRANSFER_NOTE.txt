ПЕРЕДАЧА ПРОЕКТА BLADES OF WAR — версия 0.0.4

ЧТО ЭТО
Настоящая история Twine 2 / SugarCube 2, собираемая в один HTML.
Не сайт-имитация. Старый архив v0.0.1 остаётся только как история.

КАК ИГРАТЬ
Открыть dist/BladesOfWar.html в браузере. Интернет не нужен.

КАК СОБИРАТЬ
npm install
npm run build     (.twee -> dist/BladesOfWar.html)
npm run check     (78 автопроверок логики и интерфейса)
npm run verify    (сборка + проверки)

ГДЕ ЧТО МЕНЯТЬ
Все тексты, имена, цены, локации  -> src/js/005-data.twee
Диалоги и реплики                 -> src/js/005-data.twee (поле dialog;
                                     say = живая реплика героя,
                                     text = подпись на кнопке)
Внешность персонажей              -> src/js/005-data.twee (поле appearance)
Оформление и палитра              -> src/ui/900-styles.twee (:root)
Логотип                           -> assets/logo-192.png, встроен в CSS
Работы и оплата                   -> src/js/005-data.twee (поле jobs у локаций)
Логика труда и репутации          -> src/js/055-work.twee
Репутация в панели                -> src/js/110-ui.twee (renderOrgs)
Выдвижная панель                  -> src/ui/900-styles.twee (.bow-drawer)
Лента диалога                     -> src/js/110-ui.twee (renderDialog)

ВАЖНО
- Поселение "Студёный Брод" придумано разработчиком как ТЕСТОВОЕ.
  Оно не является каноном и меняется в одном файле без правки кода.
- Авторский текст мира (short story description rus.txt) не изменялся.
- Визуальная проверка в реальном браузере разработчиком не выполнялась:
  в песочнице нет Chromium. Проверены логика, разметка и отсутствие
  ошибок JS. Глазами игру смотрит владелец.

ТЕХНИЧЕСКИЕ ЛОВУШКИ (чтобы не наступить снова)
- StoryInit не срабатывает при ручном запуске без Engine.runUserInit().
- Аргументы виджетов приходят строками; объект станет "[object Object]".
- Макросы внутри HTML-атрибутов ломают парсер. Кнопки собирать строкой.

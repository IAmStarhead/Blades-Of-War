# Мужское тело — заход 1 из 10: общие пропорции

Слева `male-body-surface-trial`, справа самостоятельная пробная копия генератора. Мужчине немного сближены центры плеч (.204 → .195 до масштабирования), чуть разведены центры бёдер (.084 → .090), сужена талия (радиус около 1.018: .146 → .139) и слегка изменён радиус таза. Длины конечностей, рост, форма головы и шеи не менялись. Перемещение костей плеч/бёдер и соответствующей геометрии выполнено в пробном генераторе; это не финальный риг. Женская геометрия не изменена. Исподнее — прежний временный рисунок на теле, верхняя одежда скрыта для осмотра.

Цель — сравнить статичный общий силуэт, не назвать пропорции правильными автоматически. На фасном снимке талия читается немного уже, расстояние между ногами увеличилось, руки чуть ближе к торсу. Разница в профиль небольшая. По-прежнему видны плоские/пересекающиеся плечи, простые кисти и невыраженные формы мышц и суставов, стык шеи не заделан; сзади есть световая полоса и тёмный участок паха. В игру не интегрировано, визуальная оценка — за пользователем. Тестовых поз недостаточно для подтверждения одежды и движения; их сейчас не считать приоритетом.

Проверка: `node tests/male-body-proportions-trial.mjs`, `npm run verify`. Автотест проверяет мужские/женские геометрии обоих народов, метрики костей, топологию и веса, но не художественное качество.

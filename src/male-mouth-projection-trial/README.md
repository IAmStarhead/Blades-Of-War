# Проба проекции мужской области рта

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, `/src/male-mouth-projection-trial/`. Слева `nose-form-study-trial`, справа на отдельной копии выдвинута область мужского рта. Обе колонки сохраняют пробу носа и переход глаз; женская фигура не изменена. Оригиналы игры и прежние пробы не заменены.

Плавная симметричная деформация перемещает вперёд не только губы, но и окружающую область и верхнюю губу, с затуханием к нижней части носа и подбородку. Текстура губ и линия под ними остались прежними. Зона затухания частично доходит до основания носа; нормали смешаны с пересчитанными (60%), поэтому это приблизительная форма и освещение.

В профиль рот выступает немного больше, но наклон от носа ещё заметен; в 3/4 может появиться впечатление выпуклой зоны над губой и переход освещения. Не считать результат анатомически законченным и не интегрировать без одобрения. Сетка мужской головы — 166 578 вершин, рот и глаз по-прежнему нарисованы, игровая анимация не проверялась.

`node tests/male-mouth-projection-trial.mjs` проверяет ограничение области и конечность координат/нормалей. Браузерное сравнение двух колонок: максимум изменения мужской координаты Z 0.009038, изменения в заданной области; текстуры одинаковы, женская голова и оба тела совпадают. Есть снимки обеих сторон, фас, 3/4, другой свет, без рисунка, полный рост и статические позы. `npm run verify` — 232/232; визуальное качество тестами не подтверждается.

# Head form study (isolated)

Three parameter variants, each with a female and male head, generated by a new procedural surface. These are rough studies based on the same topology, not three independently sculpted meshes and not replacements for game characters. Thin surface marks indicate facial features; there are no textures or protruding eyeballs. The output is schematic and has not been approved for use in the game.

Run with Vite, then open `/src/head-study/`. The three view buttons rotate the six heads. Screenshots are in `docs/previews/head-study/`.

# Проба отдельной поверхности глаза

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, `/src/eye-anatomy-patch-trial/`. Слева предыдущая проба `eye-surface-orientation-trial`; справа поверх неё добавлены неподвижные выпуклые участки белков, радужек, зрачков и маленькие белые блики. Участки прикреплены к голове и не поворачиваются к камере. Рисованные глаза под ними не удалены: это черновой эксперимент с посадкой, а не полноценные веки или глазные яблоки.

**Результат неудачный:** в фас правые глаза слишком яркие и раскрытые, форма радужки не повторяет одобренный пользователем рисунок, а в профиль участок плохо стыкуется с нарисованными веками и выглядит выпирающим. Блик искусственный, не отражение света. Поэтому проба не предложена как исправление и не интегрирована в игру. Сохранены унаследованные проблемы рта и тени под носом; голову (166 578 вершин) нельзя считать готовой для игры. Настоящее моргание и игровая анимация не проверены.

`node tests/eye-anatomy-patch-trial.mjs`: две симметричные закреплённые группы с конечными координатами. В браузере проверено отсутствие различий между колонками в геометрии голов, тел и текстурах, а также сняты ракурсы и статические позы. `npm run verify` — 232/232. Технические тесты не подтверждают художественный результат.

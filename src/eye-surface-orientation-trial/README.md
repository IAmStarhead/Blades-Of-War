# Проба наклона поверхности мужских глаз

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, `/src/eye-surface-orientation-trial/`. Слева `iris-shape-trial`, справа — отдельная геометрическая проба с той же текстурой глаз. Игра и прежние пробы не заменены.

Локальная плавная симметричная деформация уменьшает наклон поверхности головы в области обоих глаз, не подменяя рисунок по ракурсу. Нормали смешиваются с изменением пересчитанных нормалей, поэтому освещение является приблизительным. Мужская текстура глаз, женское лицо, уши, шея и тело между вариантами не меняются.

В снимках глаз сбоку изменился лишь незначительно; устранение ощущения взгляда на зрителя не доказано. На виде без рисунка остаются слабые полосы под глазами, а освещение чувствительно к деформации. Это не объёмное глазное яблоко, не готовая игровая модель и не принят пользователем вариант. Унаследованная сетка слишком плотная (166 578 вершин); прошлое экспериментальное осветление под носом сохраняется.

`node tests/eye-surface-orientation-trial.mjs` проверяет ограничение геометрической области и конечность данных. В браузере подтверждены одинаковая мужская текстура, неизменность женской головы/текстуры и обоих тел и ограниченная зона изменения мужской геометрии. `npm run verify`: 232/232. Эти проверки не устанавливают художественного качества или пригодности к анимации.

# Isolated full-body anatomy study

Two static adult bald figures for proportion review. These are **not** game characters, do not replace the existing cast, and have no skeleton, skin weights, clothing, animation or game-scene lighting. The meshes are not fitted to the supplied photographs. Their hands come from the anatomical source mesh; they are not a redesign of the existing game's hands. The flat brow guides and eyes are temporary.

Each head and body is one continuous surface, derived from the [MakeHuman Community](https://github.com/makehumancommunity/makehuman) `data/3dobjs/base.obj` mesh and `caucasian-female-young` / `caucasian-male-young` morph targets, the same underlying source as the previously reviewed head B. The [MakeHuman asset license](https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.ASSETS.md) places these assets under CC0; no MakeHuman program code is included. The complete morphed surfaces are simplified to approximately 16,000 triangles per figure, rather than attaching the earlier separately decimated head: this avoids a visible severed neck. Consequently the face surface is the same source/morph but is not an identical copy of the earlier isolated head mesh. Eye and brow guides reuse the prior study. One shared neutral skin material and lighting are applied. The body proportions and lighting are provisional and require visual approval, especially under game conditions.

`tools/build-body-study.py` records the extraction/decimation procedure. Supply the MakeHuman base OBJ and the two targets; it requires Python `numpy`, `trimesh` and `fast-simplification`. To view the study, run Vite and open `/src/body-study/`. Actual browser captures are in `docs/previews/body-study/`.

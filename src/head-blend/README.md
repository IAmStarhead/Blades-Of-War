# Head smoothing comparison

Isolated study based on the CC0 MakeHuman-derived mesh documented in `../head-reference/README.md`. Each male/female pair keeps the female head unchanged and applies a different amount of local geometry smoothing to the male head. The alternative comparison layout shows the *same male base* before/after for each level, to make the effect visible independently of sex differences. Eye sockets, nose, lips, silhouette and neck edge receive protection from the smoothing mask; this is a preview, not a production-ready deformation. It does not reduce polygon count. No game character or animation is modified.

Run Vite and open `/src/head-blend/`. Screenshots: `docs/previews/head-blend/`.

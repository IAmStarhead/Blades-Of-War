# Уточнение перехода глаза к переносице

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, затем `/src/inner-orbit-refine-trial/`. Слева прежняя `inner-orbit-transition-trial`, справа более глубокое и немного шире затухающее углубление по обеим сторонам переносицы. Это разные варианты одной деформации, а не последовательное наложение двух проб. Сохранена одинаковая статичная текстура глаз без накладных глаз и движения зрачков по камере.

Разница с предыдущим вариантом очень мала, убедительного дополнительного улучшения взгляда не видно, особенно в полный рост. Это проба, не утверждённая замена предыдущего варианта. Нормали смешиваются с пересчитанными, свет влияет на результат; в профиль глаз по-прежнему является рисунком на поверхности лица. Рот, нос ниже глаз, женщины, уши и шея не редактировались. Сохраняются прежние ограничения: под носом экспериментальная правка нормалей, голова имеет 166 578 вершин, моргание и игровая анимация не проверены; в игру проба не включена.

`node tests/inner-orbit-refine-trial.mjs` проверяет границы, двусторонность и конечность деформации/нормалей. Браузерное сравнение двух колонок: максимальная разница Z мужской головы 0.000700, текстуры, тела и женская голова совпадают; изменение ограничено указанной зоной. Снимки: фас, оба профиля и 3/4, другой свет, форма без рисунка, полный рост и статические позы. `npm run verify`: 232/232. Художественное качество тестами не устанавливается.

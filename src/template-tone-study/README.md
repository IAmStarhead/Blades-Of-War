# Character Template: tonal style experiment

Standalone visual trial on the actual Male.fbx and Female.fbx in the user-provided `Character_Template.zip`, read at runtime; originals, the game and other trials are untouched. Open `/src/template-tone-study/` with Vite. Left: original template geometry (displayed with the same neutral toon lighting, not its original material); right: edited copy. No assets from Project Zomboid are used.

The edited geometry is uniformly subdivided twice, welded by position and given smooth normals, with restrained local depth adjustments around nose, cheeks and eye region. This improves some shading continuity, but increases triangle count by 16x and is not an optimized low-poly asset. A ray-projected transparent canvas layer provides simple dark eyes, eyebrows and soft tonal hints; its shadows are painted and do not follow the light. Body lighting uses a linearly filtered eight-entry toon ramp. Temporary ellipsoid ear placeholders are separate and poorly fitted. No clothing, hair, skeletal rig, skin weights, animation, game integration, mobile performance validation, or production-ready topology. Source template remains in its original T-pose.

This is a rough experiment, not a successful Zomboid-style character: the original templates lack modeled facial anatomy and ears; forehead and jaw are oversized/pointed, facial features still appear tiny and vague, noses and profiles are not convincing, ears are missing or detached, and the T-pose makes the body comparison limited. Smoothing does not repair silhouette. Proper manually modeled facial planes, eyes and ears, proportion work and clean topology would be required; changing shader and blurring paint alone cannot provide them. Asset licensing/redistribution must be verified before any integration.

Desktop browser checks included both sexes, front, profile, three-quarter, opposite angle, switched light and face-paint toggle, full figure; mobile capture for both sexes. `npm run verify` passed 232/232; this is not an artistic or animation validation. References: [Zomboid face options screenshot](https://reddit.com/r/projectzomboid/comments/1v1nd3r/lf_mods_that_add_more_female_vanilla_face_options), which may include modded options.

# Отдельная проба тени и рта

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, открыть `/src/eye-shadow-neutral-trial/`. Слева — предыдущая orbital-neutral проба, справа — добавленная мужская правка. Исходные игровые персонажи не заменены. Женщина и шея между колонками не меняются. Эксперимент CSG из предыдущей пробы здесь отключён.

Отдельно ослаблена нарисованная дымка над бровями с защитой тёмных штрихов и сглажен переход геометрии в надбровной области. Рот перерисован с плоскостями губ, более прямой линией смыкания и линией под губой. Это рисунок на текстуре, не новая объёмная геометрия губ. На скриншотах эффект ослабления тени небольшой, тень от геометрии/освещения всё ещё видна; рот также выглядит тонким на обычном масштабе. Нейтральность требует оценки пользователем, результат не считать окончательным.

Проверка `node tests/eye-shadow-neutral-trial.mjs`: границы и конечность изменений геометрии. Сравнение живых копий в браузере: женская геометрия и текстура одинаковы, геометрия тела обоих полов одинакова, изменения мужской текстуры ограничены полосами бровей и рта. `npm run verify`: 232/232. Проверки не подтверждают визуального качества или анимации.

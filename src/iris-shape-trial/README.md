# Проба формы мужских радужек

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, `/src/iris-shape-trial/`. Слева — прежние нарисованные глаза из `calm-gaze-return-trial`, справа — отдельная проба. Оригинальные игровые модели и старые пробы не заменены.

Справа рисунок мужских радужек и зрачков локально сжат по горизонтали (в центре области приблизительно до 90% ширины) с плавными краями. Это статическая симметричная правка текстуры, не перемещение глаз за камерой и не объёмная модель; исходные блики сохраняются в используемых фрагментах рисунка. Геометрия, женщина, шея, тело и осветление под носом между колонками не меняются.

В фас различие очень небольшое, в профиль глаз по-прежнему может казаться обращённым на зрителя; гарантировать решение эффекта «голубиного» взгляда нельзя. Текстура искажает не только зрачок, но немного прилегающие пиксели радужки и белка. Унаследованные нормали под носом и очень плотная голова являются экспериментом, не готовым к игре.

`node tests/iris-shape-trial.mjs` проверяет симметрию и ограниченность преобразования. Браузерное сравнение: женская текстура/геометрия и тела одинаковы, мужская геометрия и нормали одинаковы, 183 изменённых пикселя текстуры находятся только в зонах глаз. `npm run verify`: 232/232. Автотесты не подтверждают художественное качество или анимацию.

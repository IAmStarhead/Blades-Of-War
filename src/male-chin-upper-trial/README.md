# Проба перехода от нижней губы к подбородку

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, `/src/male-chin-upper-trial/`. Слева `male-chin-profile-trial`, справа вариант с дополнительной плавной симметричной геометрической проекцией выше подбородка, под нижней губой. Это замена функции подбородка, не двойное применение предыдущей. Губы, рисунок и линия под губой сохранены; нос, глаза, женская фигура, уши и шея не меняются между колонками. Игровые модели и прошлые пробы не заменены.

В профиль переход под губой менее глубокий, хотя заметная впадина сохраняется и форма нуждается в оценке пользователя. Нормали смешаны с разностью пересчитанных нормалей на 50%, освещение приблизительное. Сетка мужской экспериментальной головы содержит 166 578 вершин; анимация и моргание не проверены. В игру не интегрировано.

`node tests/male-chin-upper-trial.mjs` проверяет ограничение общей деформации подбородка, конечность координат и нормалей. Браузерное сравнение двух колонок: мужская разница Z максимум 0.003198, ограничена верхней частью подбородка; обе текстуры, женская голова и тела совпадают. Снимки: фас, оба профиля, оба 3/4, другой свет, без рисунка, полный рост и статические позы. `npm run verify` — 232/232; художественный результат автоматические тесты не подтверждают.

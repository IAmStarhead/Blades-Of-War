# Low-poly woman — early standalone test

A visual test, not a finished character or replacement for the game/editor standards. The CC0 MakeHuman-derived female body from `../body-study/bodies.json` (see its README for attribution) was decimated from 16,000 to 4,500 triangles with fast-simplification; it was not manually retopologized to match the reference images. Flat/creased normals reveal facets and a five-step Three.js toon gradient supplies the lighting. The prior experimental arm and eyelid deformations, eye/brow guides and close-fitting garment shells are reused from angular-trial; the clothing is not tailored or simulated. Hair remains hidden. The pose is static and has no skeleton. No production assets were changed.

Open `/src/lowpoly-woman/` through Vite. Published screenshots are in `docs/previews/lowpoly-woman/`.

# Проба женского подбородка в профиль

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, затем `/src/female-chin-forward-trial/`. Слева `chin-ear-visible-trial`, справа на отдельной копии ещё немного выдвинут вперёд центр нижней части женского подбородка. Сохранены нос, глаза, губы и форма мужского лица; уши в обеих колонках имеют прежнее статическое затемнение. Игровые модели и предыдущие пробы не заменены.

Деформация симметрична и плавно затухает к челюсти и нижней губе; нормали смешиваются с разностью пересчитанных нормалей на 50%, поэтому свет приближённый. В профиль подбородок отделяется от линии под губой, но справа он может восприниматься более угловатым. Не считать форму окончательной до оценки. Анимация и моргание не проверены; предшествующая мужская пробная голова остаётся очень плотной (166 578 вершин), в игру не интегрировано.

`node tests/female-chin-forward-trial.mjs` проверяет ограничение и конечность геометрии/нормалей. Браузерное сравнение: максимальное изменение женского Z 0.004487 только в зоне подбородка; текстуры, тела и мужская голова идентичны между колонками. Снимки включают оба профиля, фас, 3/4, другой свет, без рисунка, полный рост и статические позы. `npm run verify` — 232/232; художественный результат тестами не подтверждается.

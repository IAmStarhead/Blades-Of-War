# Мужские дельты и грудь — заход 6

Сравнение: слева заход 5, справа новая отдельная проба. В каждую мужскую руку добавлены три промежуточных кольца между плечевым переходом и верхом руки (+126 вершин с дубликатами UV-шва), объём снаружи и по глубине плавно сходит к руке. Усилен объём грудных мышц и их разделение у грудины. Ориентиры: [Clip Studio о дельте и руке](https://www.clipstudio.net/how-to-draw/archives/162629), [Proko о грудных мышцах](https://www.proko.com/course-lesson/how-to-draw-pecs-form). Женское тело и мужские ноги не изменены. Лицо и шея прежние; оттенок шеи — статический, не настоящая тень от челюсти.

Дельта читается лучше, но похожа на округлый бугорок, верх плеча остаётся уплощённым, подмышечные складки сохраняются, а грудь по-прежнему не имеет убедительного разделения и в профиль может выглядеть чрезмерно выпуклой. Это эксперимент, не замена игровой модели. Деформация/одежда и UV новых колец не проверены, соединение не доказывает отсутствие самопересечений.

`node tests/male-deltoid-relief-trial.mjs` проверяет нормированные веса, допустимые индексы, неизменность женской геометрии и мужских ног для двух народов. `npm run verify` — 232/232. Тесты не оценивают анатомию и деформацию.

# Мужской профиль и тень под носом — отдельная проба

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, `/src/face-profile-trial/`. Слева — `mouth-balance-trial`, справа — повторная правка. Игровые персонажи и прежние пробы не заменены.

На мужской копии возвращена значительная часть предыдущего отведения области рта назад и сделан более плавный переход под кончиком носа. Отдельно ослаблена нарисованная тень ниже ноздрей без стирания ноздрей и губ. Женщина, шея, тело, уши и глаза не менялись.

Сравнение без текстуры показывает, что тёмная область под носом остаётся даже без рисунка: вклад дают форма и освещение. На рендерах она всё ещё заметна; проба не доказывает, что дефект устранён. Глаза нарисованы на поверхности головы, без отдельных глазных яблок, и при профильном ракурсе могут создавать ощущение взгляда на камеру. В этой пробе направление глаз не исправлено; для него нужна отдельная проверка с объёмом/параллаксом, без обещания готового результата.

Число вершин головы мужчины унаследовано от `mouth-form-trial`: 166 578, это эксперимент, не пригодный как есть для игры. `node tests/face-profile-trial.mjs` проверяет границы и конечность геометрии; браузерное сравнение подтверждает идентичность женской головы и текстуры, тел и ограниченность мужских изменений; `npm run verify` — 232/232. Визуальная приёмка и игровая анимация не подтверждены.

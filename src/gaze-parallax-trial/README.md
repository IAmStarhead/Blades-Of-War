# Проба параллакса нарисованных глаз

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, `/src/gaze-parallax-trial/`. Слева — `eye-nose-light-trial`, справа — самостоятельный эксперимент, оригиналы не заменены.

Справа белок и веки остаются нарисованными; зрачок, радужка и блик перерисованы на текстуре. Выбранный ракурс стенда меняет изображение из 17 заранее созданных карт, сдвигая радужки к центру лица для приближённого эффекта параллакса. Это **не объёмный глаз**, не физический параллакс и не полноценное слежение за реальной камерой: учитываются только углы управления стенда и тестовый поворот головы, не произвольные положения камеры. Могут быть скачки между картами и впечатление косоглазия. У обоих вариантов сохранено экспериментальное осветление под носом из предыдущей пробы; оно сделано нормалями, а не изменением формы.

На проверенных профилях зрачок и блик видны лучше, чем на тонком геометрическом срезе, но глаз по-прежнему выглядит плоским и может казаться смотрящим к зрителю. В три четверти изображение может выглядеть странно; при движении, произвольной камере и игровой анимации эта схема не проверена и не пригодна для интеграции. Голова всё ещё слишком плотная (166 578 вершин). Женщина, шея и тело не менялись.

`node tests/gaze-parallax-trial.mjs`: выбор карт ограничен допустимым диапазоном. В браузере проверены совпадение геометрии и нормалей обоих полов, тел и женской текстуры; разница мужской текстуры ограничена глазами; переходы фас/профили и отключение рисунка работают. `npm run verify`: 232/232. Проверки не устанавливают визуальную корректность.

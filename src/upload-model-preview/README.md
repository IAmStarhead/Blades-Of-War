# Uploaded GLB screenshot scene

Standalone screenshot viewer for the two user-uploaded root-level GLB files; no changes to the models or game/editor. Uses their original geometry and vertex colors with neutral preview lighting, not a cel shader. URL parameters: `who=woman|man|both`, `face=1`, `angle` in radians. Open through Vite at `/src/upload-model-preview/`; screenshots are in `docs/previews/uploaded-models/`. Rotation and camera affect only this preview.

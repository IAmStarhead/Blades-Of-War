# Проба направления взгляда в профиль

`npm ci`, `npm run dev -- --host 0.0.0.0`, открыть `/src/eye-profile-trial/`. Слева `face-profile-trial`, справа — отдельная попытка, игровые модели не заменены.

Рисунок глаз в предыдущей модели расположен на поверхности головы. В пробе частично развёрнуты поверхности под каждым глазом в направлении вперёд путём плавной локальной геометрической деформации; рисунок глаз не меняется, никаких привязанных к камере глаз и переключения текстур нет. Женщина, шея, тело, рот и нос относительно предыдущей пробы не изменены.

Результат НЕ доказал исправления взгляда: при профиле глаз всё ещё может выглядеть направленным к наблюдателю; без текстуры под глазами заметны новые полосы и неоднородное освещение. Это не объёмное глазное яблоко и не пригодный к интеграции вариант; сетка головы унаследована с 166 578 вершинами. Тень под носом из предыдущей пробы также остаётся. Не следует заменять текущих персонажей этой пробой.

`node tests/eye-profile-trial.mjs`: конечность и ограничение геометрической зоны. Браузерное сравнение: женские голова/текстура и тела совпадают; текстуры мужчины одинаковы, изменения геометрии только в зоне глаз. `npm run verify`: 232/232. Тесты не проверяют художественное качество или анимацию.

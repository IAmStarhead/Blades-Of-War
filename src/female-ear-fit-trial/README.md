# Female ear fitting trial

Left is `ear-join-trial`. On the right, the female trial removes the previous angular transition strips, mirrors one extracted reference ear to both sides for consistent shape, and places both ears slightly closer to the head. The small overlapping roots remain. The male ears, transition strips, head and body are the same on both sides. Hair remains hidden. The user can compare front, three-quarter and both profile views.

This does not weld the ear to the head: the head, extracted ear and overlapping root are separate surfaces. Cropped edges, patches and light-colour differences remain visible; positioning still needs artistic review and animation is not tested. The ear geometry is extracted from a CC0 MakeHuman-derived head, with provenance in `../head-reference/README.md`. No original game models, previous studies or editor presets are changed or replaced.

Open `/src/female-ear-fit-trial/` in Vite. PNG comparisons in `docs/previews/female-ear-fit-trial/`. Browser checks verified male geometry unchanged between copies, female mirroring, finite positions and controls at desktop/mobile sizes; this does not establish visual quality or animation compatibility.

# Проба мужского подбородка

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, `/src/male-chin-profile-trial/`. Обе колонки основаны на `male-lip-profile-trial` с понравившимся пользователю профилем губ; справа дополнительно выдвинут подбородок. Предшествующая отвергнутая «мордочка» не используется. Игровые модели и прежние пробы не заменены.

Симметричная плавная деформация добавляет проекцию центральной части мужского подбородка с затуханием к нижней челюсти и губе; текстура не меняется, линия под губой остаётся. Женская фигура, нос, глаза, уши, шея и тела между колонками не меняются. Нормали смешиваются с разностью пересчитанных нормалей на 50%, поэтому освещение приблизительно.

В профиль подбородок стал чуть заметнее, но переход под губой может выглядеть выраженным; сравнение на полном росте почти незаметно. Не считать форму принятой до оценки пользователя. Мужская пробная голова содержит 166 578 вершин, анимация и моргание не проверены; не интегрировать в игру без одобрения и оптимизации.

`node tests/male-chin-profile-trial.mjs` проверяет ограничение геометрии и конечность координат и нормалей. Браузерное сравнение: max разница мужских координат Z 0.004499 в зоне подбородка, обе текстуры, женская голова и тела совпадают. Сняты оба профиля и 3/4, фас, другой свет, без рисунка, полный рост и статические позы. `npm run verify` — 232/232; художественное качество тестами не устанавливается.

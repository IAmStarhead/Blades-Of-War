# Restore calm facial expression — comparison trial

Left reconstructs the rejected `face-features-trial` (large round eyes, stretched painted lips and added relief). Right uses the original eye and earlier mouth artwork on the same `face-form-study` base, without the last additional relief. It also softens painted skin shading in a bounded forehead region above the eyebrows on a cloned texture. The male's earlier mouth/smile returns; the female mouth is the earlier painted version, not a new sculpt. Both versions have the same ears; no further ear work in this pass. All earlier trials and original game models are untouched.

The original head texture contains broad painted brow and eye shadows, particularly around the north male brow. Geometry and actual lighting also affect shading, so reducing the painted forehead haze alone is not a demonstrated anatomical fix: the right-hand image still has a noticeable dark area around the brows. Neither actual eye sockets nor eyebrows have been repositioned. Eye size is reverted, not a successful intermediate redesign; the user previously requested larger but relaxed eyes. Lips are not yet reworked volumetrically, and ear faceting and seams remain. Ear geometry provenance: CC0 MakeHuman-derived (`../head-reference/README.md`).

Desktop/mobile browser checks covered both sexes, camera views, lights and body scale, checking unchanged body, head Y, protected central nose/lip coordinates and ear indices. `npm run verify` passed 232 tests. Not a substitute for visual or animation acceptance. Screenshots are in `docs/previews/face-calm-trial/`.

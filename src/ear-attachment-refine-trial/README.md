# Ear attachment refinement — separate trial

Both sides use the previous `ear-surface-reveal-trial` approach (broader source ear plus local head recess); left is its earlier appearance. On the right, male ears have a small low/back set of triangles removed based on their local position. The large rear source-mesh flap is reduced in the shown profile, but a smaller angular edge and a lighting depression remain; deleting triangles can create an open boundary and is not a weld. Female right uses a wider source extraction at the lower/front edge as an attempt to recover the lobe transition. The difference there is slight and the unfinished transition is not demonstrably solved. Source ear is CC0 MakeHuman-derived; see `../head-reference/README.md`.

No original game asset or preset was replaced; face textures and neck were not changed. Ear/head and head/neck joins are still unwelded. The earlier head depression creates visible shading at some views, and this is not suitable for game integration without review. PNGs include both profiles, alternate lighting, and static turn/tilt; they do not validate an animation cycle. `node tests/ear-attachment-refine-trial.mjs` checks the trimming rule on a synthetic mesh; `npm run verify` passed 232/232. Tests do not prove visual quality or topology.

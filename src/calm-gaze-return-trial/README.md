# Возврат прежних глаз на отдельной копии

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, открыть `/src/calm-gaze-return-trial/`. Слева отвергнутая `gaze-parallax-trial`, справа прежние нарисованные глаза из `face-profile-trial`, включая исходный блик. На обеих копиях сохранено осветление под носом из `eye-nose-light-trial`. Старые пробы и игровые модели не заменены.

Справа нет объёмных накладок и подмены радужки при смене ракурса; это возврат, а **не решение взгляда в профиль**. Плоский глаз сбоку по-прежнему может выглядеть смотрящим на зрителя. Осветление под носом основано на локальной правке нормалей, не на изменении формы; при другом свете ещё возможны дефекты. Проба использует унаследованную очень плотную сетку головы (166 578 вершин), не готовую для игры.

Браузерное сравнение подтвердило: справа текстура мужчины идентична `face-profile-trial`, нормали — `eye-nose-light-trial`, отсутствуют накладки радужек; между колонками геометрия головы и тела одинакова, женская текстура и геометрия совпадают. `npm run verify`: 232/232. Визуальное качество и игровая анимация проверками не подтверждаются.

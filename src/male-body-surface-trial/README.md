# Мужское тело: статическая проба плеч и конечностей

Справа локальная правка поверх `body-anatomy-first-trial`, слева её исходный вариант. Работали только с мужскими конечностями: верхние кольца руки сужены и отведены внутрь торса, чтобы уменьшить плоскую «крышку» плеча; силуэт верхней руки, локтя, предплечья, бедра и икры меняется по длине немного заметнее, чем в прошлой пробе. Это правка существующих поверхностей, **не полная пересборка** и не сварка плеча. Скелет, длины, веса, торс, голова, руки женщины и её тело не изменены по сравнению с предыдущей пробой. Без верхней одежды только для оценки тела; нарисованное старое исподнее не является новой одеждой.

Недостатки: в профиле и ¾ по-прежнему заметен срез/пересечение плеча, в фас есть уступ; руки остаются слишком цилиндрическими, у кисти нет отдельных четырёх пальцев, пропорции и рельеф ног ещё требуют работы. На виде сзади заметен перепад/полоса освещения спины и разрыв вида в паху. Шея не исправлена. Формы предназначены для оценки в статичной позе, а не как финальная анимированная модель. Старые игровые модели не заменены.

Тест `node tests/male-body-surface-trial.mjs` для обоих народов: скелет, UV, индексы и веса неизменны, женские координаты не изменены, мужские изменения ограничены конечностями. `npm run verify` — 232/232. Тест не оценивает анатомию и видимость стыков.

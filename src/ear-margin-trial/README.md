# Ear-margin experiment (incomplete)

The left copy matches `seam-softening-trial`'s right copy. On the right, the male trial removes the earlier overlapping ear-join strips and both sexes receive another inward projection of the cropped ear margin toward the head, followed by averaged normals. The original ear geometry is separately created for each figure; head and body vertex positions and neck length are unchanged. CC0 MakeHuman-derived ear geometry provenance is documented in `../head-reference/README.md`.

The visual change is small. Visible ear-root fragments and the head/neck seam remain: these are overlapping meshes, not a welded surface. No attempt is made here to repair other body or clothing joints. This is a static trial, not an animation compatibility test or game integration; original characters and earlier trials are untouched.

Run at `/src/ear-margin-trial/`; comparisons are in `docs/previews/ear-margin-trial/`. Desktop/mobile browser checks compared head/body positions, checked independent body textures and finite nonempty ear geometry, and exercised view controls. These checks do not establish artistic quality or compatibility with animation.

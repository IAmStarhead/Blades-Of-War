# Unsuccessful jaw anatomy trial

An isolated experiment on cloned original game heads, checking front, three-quarter and side views against the reference images in origin/main commit 7086119. Ear faces are removed on the trial only, and the female mouth texture is enlarged. It remains a deformation of the existing radial head mesh, not a new anatomically constructed head. The intended jaw shape was not achieved: the front chin has an unnatural central point, the lower back of the head still bulges into the neck, and the original neck join remains visible. Do not integrate this trial into the game.

Screenshots in `docs/previews/game-anatomy-profile/` show original left, trial right. The original game characters, old heads, and earlier trials are untouched. No animation or rig compatibility demonstrated. `tests/game-anatomy-profile.mjs` verifies clone isolation and finite geometry, not artistic quality.

# Raised eyes and larger ears, isolated comparison

Open `/src/eyes-raised-trial/` on Vite. Both figures are copies of the earlier game-character trial; original game models and previous work are untouched. Left reconstructs `feature-retouch-trial`; right moves the existing eye/brow drawing upwards 5 pixels from the unretouched texture (left had moved it 3.5 pixels down), with the same horizontal placement and original eye drawing. This is a texture warp only: sockets are not moved, and suitability of placement and expression is a visual judgment. Nose and lips are not edited in this pass.

Ears on the right are 1.23 times the baseline height (left 1.14, about 8% difference compared with the previous trial), both have the same 1.035 depth scale. Separate ear meshes retain their existing irregularities, overlaps and male asymmetry; head width and head/body positions are unchanged. Normals-only smoothing from the previous trial is applied equally to both.

The meshes have **not** been unified. In the game, the body is a skinned mesh and the head is a separate rigid mesh attached to the head bone. Merely concatenating their triangles would not weld the boundary or solve the visible join. A true continuous surface requires compatible boundaries, UV/material work and skin weights across neck/head, then testing head turns and other animations. Earlier rigid bridges created collars or short-looking necks; neither is reused here. The visible profile seam is still present.

Desktop captures cover both sexes, multiple angles, clay, opposite light and distance; mobile browser captured both. Browser comparison confirms head/body vertex positions and normals identical between columns, and ear height increased ~7.9% on right; `node tests/eyes-raised-trial.mjs` checks direction and relative scaling. `npm run verify` 232/232. These tests cannot certify artistic placement, stitching or animated deformation. Source for reference-derived ears: `../head-reference/README.md`.

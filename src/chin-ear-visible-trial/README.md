# Более заметная проба подбородков и затемнения ушей

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, открыть `/src/chin-ear-visible-trial/`. Слева прошлый `chin-ear-shading-trial`, справа отдельная проба для обоих персонажей. Исходные модели и предыдущие варианты не заменены.

Справа дополнительная плавная симметричная проекция подбородка мужчины и женщины, включая небольшое затухание под губой. Рисунок лица и линия под губой не изменены. В обоих ушах более выраженная статическая подкраска вершин внутренней части, заменяющая (не суммирующаяся с) прошлую слабую подкраску; геометрия ушей не меняется. Это не динамическая тень, и тени на остальных частях лица намеренно не усиливались.

В профиль подбородки читаются сильнее, но женский может показаться менее мягким, а мужской — более массивным. Оттенок в ушах остаётся локальным и на некоторых ракурсах/свете может быть едва заметен. Нормали подбородков смешиваются с разностью пересчитанных нормалей на 50%, это приблизительное освещение; результат требует оценки пользователя. Шеи и тела не менялись. Мужская сетка содержит 166 578 вершин; анимация/моргание не проверялись. В игру не интегрировано.

`node tests/chin-ear-visible-trial.mjs`: границы и конечность деформации, затухание подкраски и неизменность тестовой геометрии уха. Браузерное сравнение: max Z мужчины 0.004233, женщины 0.004906, только зона подбородка; текстуры и тела одинаковы, геометрия четырёх ушей совпадает, цвета вершин отличаются. Сняты оба профиля, фас, 3/4, другой свет, без рисунка, полный рост и статические позы. `npm run verify` — 232/232; художественное качество и анимация тестами не установлены.

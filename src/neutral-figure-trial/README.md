# Neutral standing figure study

Standalone static experiment based on the existing 16,000-triangle, CC0 MakeHuman-derived `../body-study/` meshes (see its README for source attribution). Does not modify the saved standards, editor, or game characters. No new topology is generated. The existing editor arm-length and bust controls use values 88 and 110; the rest of the body retains original proportions, not an objective beauty standard. A weighted, symmetrical geometric arm rotation and small depth shift bring the arms closer to the torso without a skeletal rig. The hands/fingers are not remodeled. The result remains a static A-pose; deformation/skin fitting has not been proven for animation.

Eyelids are adjusted slightly, lip corners receive a small geometric tweak, temporary eyebrows are projected onto the body mesh, and eye guides are aligned to its visible eye openings. Expression and gaze still need subjective review, particularly at close range; no facial rig or expression animation exists. The temporary clothing is the same thin close-fitting shell from `../angular-trial/`, previously rejected as an unsatisfactory garment; it is a placeholder, not revised tailoring. No editor controls or game integration are provided.

Run Vite at the repository root and open `/src/neutral-figure-trial/`. Screenshots: `docs/previews/neutral-figure-trial/`.

# Ear recess and neck status

An independent comparison based on the accepted female-chin-forward version, not the facial-planes experiment that introduced under-eye stripes. On the right, an additional smooth vertex-color darkening is applied to the existing inner ear bowl for both sexes. Ear geometry, head, body, face texture and accepted chin are unchanged. The effect is a static tint, not a shadow responding to lighting. The comparison includes both profiles and alternate lighting; close-ups are crops of the full screenshots.

The neck and ear-to-head joins are **not fixed** in this trial. The rigid head and separately skinned body overlap, and shading alone cannot create a continuous surface during movement. The previous bridge experiments produced a collar/short neck and the more recent normal experiment caused streaks. They were not reused. The turn and tilt screenshots are static pose samples, not a complete animation test. No game assets or presets were replaced.

Open `/src/ear-depth-neck-trial/` in Vite. Run `node tests/ear-depth-neck-trial.mjs`; `npm run verify` passed 232/232. Tests do not establish visual quality.

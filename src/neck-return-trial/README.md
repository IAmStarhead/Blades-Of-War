# Return to the pre-bridge neck

The right-hand comparison restores the neck and head from the right-hand side of `head-refinement-trial` (the last version before the neck bridge experiments): the copied body neck remains a separate overlapping mesh, and retains the small taper previously requested. The left-hand side shows the rejected short `neck-fit-trial` bridge for comparison. No further face changes were made.

The old head/neck junction is visibly separate and is not presented as a finished animated connection. Hair and ears are hidden. No original game assets, previous studies, or editor presets are replaced; this is a static visual trial.

# Female profile and neck comparison

An isolated static follow-up shown on copies of the original game figures. Left: the previous `neck-bridge-trial` (with its short, rigid experimental bridge). Right: returns to the longer, overlapping separate neck from `jaw-neck-trial`, without that bridge. The right female head additionally adjusts forehead projection and height, nose bridge/tip, and chin projection while retaining the preceding jaw and lip work. The male head shape on the right uses the previous `jaw-neck-trial` unchanged; the neck is not a new integrated solution.

The head still uses the original game UV-mapped mesh and a smoothed lower-face displacement sampled from a CC0 MakeHuman-derived reference mesh: see `../head-reference/README.md` for provenance. No reference head is attached. The original game models and prior trials are preserved; hair, beard and ears are hidden on these copies. The head and neck on the right remain separate intersecting meshes: the rear seam and shape remain visible, so this is not a finished or animation-ready neck. The mouth is mostly texture. No game/editor integration or animation has been validated.

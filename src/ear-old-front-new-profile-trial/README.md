# Earlier front contour and newer profile experiment

Left recreates `ear-inner-relief-strong-trial` (99a8258). Right uses the same newer ears and attempts to bring their outer/upper x coordinates toward the closest points of the earlier `female-chin-forward-trial` ear surfaces, in head-local coordinates. It loads the preserved earlier comparison in an offscreen same-origin frame and reads its ear meshes, then disposes of the frame. This is a trial-only reference dependency, not production integration. The target surfaces have different topology; closest points are merely an approximation, not vertex correspondence. The displacement is tapered, limited to .0025 local units, and changes only X; pre-strip Y/Z, lower-lobe vertices and indices stay unchanged. The same upper-root overlap strip is rebuilt afterwards.

Actual adjusted vertex counts female 228/332 and male 355/529. Visual changes in front are small; this does not reproduce the earlier silhouette precisely. The upper dark spot, irregular rim, visible male pale areas and lower seams still exist. The comparison does not establish a defect-free combination; ear meshes remain overlapping rather than welded. Static head pose snapshots are present, not a full animation-cycle test. Face geometry and game assets are not replaced.

# Central candidate: straight nasal bridge

Left is the previous central nose candidate from `nose-kingdom-trial`, right is the new trial. The nasal centreline is projected onto a straight line between fixed points near the root and tip, with lateral falloff; this targets the middle bridge rather than flattening the tip or erasing the forehead transition. The centreline is tested numerically for both sexes. It is a static visual trial, not a production preset, and the perceived silhouette also depends on nearby surfaces and lighting.

Both comparisons use the same north-based character copies for controlled review; no kingdom-specific game model has been changed. The northern candidate remains in `../nose-kingdom-trial/` unchanged. Head geometry is subdivided and derives from previous trials; the existing jaw contour used a CC0 reference (see `../head-reference/README.md`). Ears and hair remain hidden, nostrils are painted, and the head/neck seam and animation have not been solved. Original game characters and previous studies remain untouched.

Vite URL `/src/straight-nose-trial/`; PNGs `docs/previews/straight-nose-trial/`; structural and centreline test `node tests/straight-nose-trial.mjs` (not a visual-quality test).

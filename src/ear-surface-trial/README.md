# Ear root surface experiment — unsuccessful

This static comparison tests whether the oval insert inside the ear can be made less prominent. Left reproduces `ear-detail-trial`'s right-hand result; right reduces the ear root ellipsoid's height and depth to 68% on copies only. Ear shape, head/body vertices and neck length are unchanged. Both copies keep the prior ear tilt and inner vertex colour. CC0 MakeHuman-derived ear source: `../head-reference/README.md`.

This did not solve the issue: the smaller insert has a conspicuous separate boundary and exposes gaps between intersecting surfaces. It is not recommended as a finished ear. The ear/head and neck/head surfaces remain separate and are not welded; motion has not been checked. Earlier trials and game characters remain unchanged. PNGs including enlarged screenshot crops are in `docs/previews/ear-surface-trial/`.

Browser checks exercised desktop/mobile view controls, compared head/body vertex positions, checked cloned textures and finite nonempty ear geometry. `npm run verify` passed; these tests do not establish artistic quality or animation compatibility.

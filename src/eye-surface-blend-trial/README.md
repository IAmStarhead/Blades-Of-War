# Проба более плавной поверхности вокруг глаз

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, затем `/src/eye-surface-blend-trial/`. Слева предыдущая `eye-surface-orientation-trial`, справа новая проба на отдельной копии. У обеих одинаковая слегка суженная статичная текстура радужек, без сдвига по камере.

Справа наклон поверхности в районе глаз меняется сильнее и затухает на большей области. Это деформация поверхности головы с рисованными глазами, а не глазное яблоко; нормали смешаны приблизительно. По снимкам фас, оба профиля и три четверти разница небольшая, исправление взгляда не доказано. В виде без рисунка заметны неровности/полосы под глазами; не считать работу готовой или интегрировать без одобрения. Форма рта и тень под носом остаются прежними, а высокополигональная экспериментальная голова (166 578 вершин) не пригодна для игры в таком виде.

Браузерное сравнение двух колонок: максимальная разница мужских координат Z 0.001917, изменения ограничены областью около глаз; текстуры одинаковы, женская голова и текстура и оба тела одинаковы. Отдельный тест `node tests/eye-surface-blend-trial.mjs` проверяет ограничение деформации и конечность нормалей. `npm run verify` — 232/232. Статичные повороты головы не заменяют проверку анимации; художественная правильность тестами не подтверждена.

# Ограниченная проба мужского профиля губ

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, `/src/male-lip-profile-trial/`. Слева нос и лицо из `nose-form-study-trial`, до отвергнутой пользователем пробы «мордочки». Справа — новая деформация, которая заменяет отвергнутую, а не накладывается на неё. Исходные игровые модели не заменены.

Небольшая симметричная геометрическая правка ограничена областью губ и затухает до основания носа; не выдвигает всю область под носом. Текстуры губ и линия под ними сохранены, женская фигура, глаза, уши и шея между колонками не меняются. Нормали смешаны с разностью пересчитанных нормалей на 45%, поэтому это приблизительный свет.

В профиль губы заметнее отделены от лица и зверообразный выступ под носом прошлой пробы отсутствует, но линия от носа по-прежнему крутая, а сами губы могут выглядеть слегка выдвинутыми/заострёнными. Художественное исправление не доказано. Мужская голова остаётся экспериментальной (166 578 вершин), анимация и моргание не проверялись. Не интегрировать без одобрения.

`node tests/male-lip-profile-trial.mjs` проверяет ограничение области и конечность геометрии и нормалей. Браузерное сравнение: максимальная разница мужских Z 0.004800 в зоне губ; женская голова, текстуры и оба тела совпадают. Сняты оба профиля, 3/4, фас, другая подсветка, полный рост, статические позы и вид без рисунка. `npm run verify` — 232/232; эти проверки не подтверждают художественное качество.

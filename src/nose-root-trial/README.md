# Nose root / forehead transition — isolated visual trial

Side-by-side follow-up to `nose-form-trial` with the user's restored pre-bridge neck. Both sides use the prior nose work; on the right a localized, shallow geometric recess is added between the eyes where the nasal bridge meets the forehead. This is intended to break the long straight forehead-to-tip profile without an exaggerated notch. It changes neither the body nor the deliberate shape of the rest of the face. Existing texture, including painted nostrils, remains unchanged.

The head is a once-subdivided copy of the original game head, with inherited reference-derived jaw shaping; see `../head-reference/README.md` for the CC0 source. Hair, ears and beard are hidden. The head and neck remain separate overlapping surfaces, their junction is not solved, and animation is not validated. This is not a production integration; previous trials and game assets are preserved. The approximate profile change must be evaluated visually, not inferred from passing tests.

Vite URL `/src/nose-root-trial/`; screenshots `docs/previews/nose-root-trial/`; `node tests/nose-root-trial.mjs` checks finite geometry, isolation and locality.

# Head-detail balance trial

Three male/female pairs are based on the same CC0 MakeHuman meshes as the earlier `../head-reference/` trial (see its README for source and license). This study compares different simplification levels, not independently sculpted faces or likenesses. A / B / C have approximately 1,560 / 2,140 / 3,700 triangles per head after the flat neck cut. The same neutral lighting, materials and embedded eyes are used across variants. The thin eyebrow guides are temporary flat geometry, not final textures. Hair is hidden.

Reducing triangles is only one component of visual balance. These images cannot establish performance or prove suitability under game lighting; no character, skeleton, clothing, animation or game lighting has been modified. Run Vite and open `/src/head-balance/`. Screenshots are in `docs/previews/head-balance/`.

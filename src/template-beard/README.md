# Template beard study

Standalone, temporary visual experiment based on the user-supplied `Character_Template.zip` / `Male.fbx`. The archive is read at runtime, not modified. The source model's facial triangles are subdivided and locally displaced for a nose; eyes, brows and mouth are deliberately simple separate flat patches. The beard is a separately modeled open polygon shell, with a separate moustache. It is not a fitted, closed or animation-ready hair mesh: it still looks like an attachment from some angles. The template has no modeled ears or complete face, and this experiment does not add them. Neutral lights and flat-shaded materials are used; this is not cel shading. No editor or game assets are changed.

Run Vite at the repository root and open `/src/template-beard/`. Screen captures: `docs/previews/template-beard/`. The model's usage and redistribution terms must be checked before game integration; free download alone does not establish them.

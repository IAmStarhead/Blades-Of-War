# Jaw profile trial

An isolated follow-up to `game-head-silhouette` using clones of original game characters. The lower jaw underside is lifted toward the neck and the chin projects modestly; female mouth texture is enlarged on a separate canvas and the underlying lip region has a small geometry adjustment. Ear triangles remain removed on the trial clones only. Bodies and original game models are unchanged. Screenshots in `docs/previews/game-jaw-profile/` show original (left) and trial (right).

Limitations: this is still a deformation of the existing head, not anatomy reconstructed from references. The neck is separate and its connection remains conspicuous; female chin can appear pointed and the mouth remains largely texture based. Static views only; no animation integration. Run Vite and open `/src/game-jaw-profile/`.

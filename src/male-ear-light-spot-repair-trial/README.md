# Проба верхнего контура мужского уха

Отдельное сравнение на копиях: слева предыдущая `ear-root-winding-repair-trial`, справа та же основа с заполнением небольшого замкнутого открытого контура в верхней части мужского уха. Найденный на правом ухе контур содержит 12 вершин; новые треугольники используют существующие вершины и нормали, направление согласовано с соседними гранями. Женский вариант не меняется. Это не сварка уха с головой.

На крупном плане мужского профиля крупное тёмное пятно стало меньше, но тонкий след остаётся. Светлая зона в фас по-прежнему видна: её причина не доказана, и эта проба не является её надёжным исправлением. Проверьте также оба профиля, три четверти и другой свет; швы и неровности сохраняются. Снимки — статические позы, полный цикл анимации не проверен. Игровые модели не заменены.

Проверка: `node tests/male-ear-light-spot-repair-trial.mjs`, `npm run verify`. Тест использует искусственный контур и не подтверждает визуальное качество или пригодность для анимации.

**Исправление:** проверка реальной сцены показала, что этот вызов добавил 0 треугольников: контур уже изменён соединительной полосой. Описание выше о заполнении было ошибочным. См. `ear-upper-opening-order-trial`, где порядок операций изменён и число добавленных треугольников проверено.

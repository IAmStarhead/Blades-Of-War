# Проба подбородка и затемнения ушных раковин

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, `/src/chin-ear-shading-trial/`. Слева `male-chin-upper-trial`, справа проба чуть более выступающего мужского подбородка и затемнения внутренних частей ушей обоих персонажей. Прежние варианты и игровые модели не заменены.

Справа усилена та же плавная геометрическая деформация центрального подбородка; предыдущий переход под губой сохранён, лицо женщины и обе шеи не меняются. В ушных раковинах мягко затемнены цвета вершин с затуханием к краям. Это **статическая подкраска**, не динамическая тень или геометрическое углубление; форма и расположение ушей не менялись. Весь остальной свет лица не усиливался, чтобы избежать тёмных пятен. Эффект в ушах и на подбородке небольшой и зависит от ракурса; в игровой дистанции его почти не видно.

`node tests/chin-ear-shading-trial.mjs` проверяет границы и конечность деформации и ограниченную подкраску уха без изменения вершин. В браузере сравнены варианты: максимальное изменение мужского Z 0.001500 в области подбородка; текстуры, женская голова, оба тела и геометрия ушей совпадают, цвет вершин ушей меняется у обоих полов. Снимки включают обе стороны, фас, 3/4, другой свет, вид без рисунка, рост и статические позы. `npm run verify` — 232/232. Художественная оценка, анимация и работа динамических теней тестами не подтверждены. Пробная мужская голова содержит 166 578 вершин; не интегрировать без одобрения и оптимизации.

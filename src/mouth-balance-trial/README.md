# Отдельная проба баланса мужского рта

Запуск: `npm ci`, затем `npm run dev -- --host 0.0.0.0` и открыть `/src/mouth-balance-trial/`. Слева `mouth-form-trial`, справа новая правка; исходные персонажи не заменены.

В базовой голове есть процедурный выпуклый участок вокруг рта (`muzzle` в `bowCharacter.js`). На копии поверх предыдущей пробы ослаблен широкий выступ в области рта; это приближение, а не точное вычитание исходного слоя, поскольку промежуточные формы тоже меняют голову. Губы перерисованы немного полнее, линия смыкания выпрямлена, линия под нижней губой сохранена. Женщина, уши, шея и тело не менялись. Виды с рисунком, без рисунка и при другом свете позволяют оценить геометрию отдельно.

На фасе новая форма отличается умеренно; из-за формы текстуры и освещения выражение всё ещё может выглядеть слегка улыбающимся. Профиль и устранение ощущения «капы» требуют оценки владельца. Это не финальная модель: у мужской головы 166 578 вершин из унаследованного деления, для игры потребуется другая топология. Динамические эмоции здесь не добавлялись.

`node tests/mouth-balance-trial.mjs` проверяет границы и конечность деформации. Браузерное сравнение: женская геометрия и текстура идентичны; геометрия тел одинакова; отличия геометрии и текстуры мужчины находятся в области рта. `npm run verify`: 232/232. Эти тесты не оценивают художественный результат или игровую анимацию.

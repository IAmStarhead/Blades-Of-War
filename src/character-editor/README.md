# Character appearance editor prototype

A separate static editor using the CC0 MakeHuman-derived body-study base (see `../body-study/README.md` for attribution). Does not alter the game's original characters. Controls currently adjust body height, arm and leg proportions, hip width, female bust and skin color; the body starts from the original standard (not the discarded style/proportion trial), with shorter arms and a slightly adjusted female bust as adjustable defaults. Arms are shortened by a bounded translation field, not by rescaling fingers. No rig, clothes, animation, hairstyles, facial editing, import or in-game integration exists yet. Slider percentages are relative control values, not anatomical measurements; 100 returns that specific control to the baseline. Morphs are provisional and must be checked visually.

Export downloads JSON with a schema, version, base ID, name, kingdom, sex and all the current slider settings. It is a settings record, **not** a model export or an in-game preset. The user must attach the exported file to the conversation; it does not automatically send or persist data to the assistant. For safety the JSON is also visible on the page. To run, start Vite from the project root and open `/src/character-editor/`.

The editor preview uses a directional light with shadow mapping, a soft fill light and procedural skin colour variation. The charcoal linen underwear is a procedural surface-material mask, not removable clothing or geometry; it follows the body coordinates approximately and has not been validated against every slider combination or animation. The settings export includes identifiers for these fixed preview materials. No changes are made to the original standards or game characters.

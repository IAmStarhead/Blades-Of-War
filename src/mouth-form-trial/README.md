# Отдельная проба формы мужского рта

Запуск: `npm ci`, `npm run dev -- --host 0.0.0.0`, открыть `/src/mouth-form-trial/`. Слева — одобренная как улучшение проба `eye-shadow-neutral-trial`, справа — новая попытка. Ничего не интегрировано в игровые модели.

На копии головы уточнена сетка и ограниченной симметричной деформацией немного убрана выпуклость вокруг рта, добавлены неглубокие плоскости обеих губ; рисунок смыкания, губ и линии под губой перерисован. Шея и женский персонаж не менялись. Кнопка «Без рисунка» позволяет отдельно увидеть геометрию при разном свете и ракурсах.

Это не финальная топология: повторное равномерное деление увеличивает число вершин мужской головы справа с 41 870 до 166 578, поэтому проба не предназначена для игры. На снимках губы всё ещё тонкие, форма и нейтральное выражение требуют оценки; гарантировать устранение ощущения «капы» нельзя. Анимация выражений не сделана.

`node tests/mouth-form-trial.mjs` проверяет границы и конечность геометрической правки. Браузерное сравнение подтвердило неизменность геометрии и текстуры женщины, тела обоих персонажей, область изменений текстуры мужчины; `npm run verify` — 232/232. Тесты не оценивают внешний вид и реальную анимацию.

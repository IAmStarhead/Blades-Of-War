# Male ear scalp fragment removal trial

Left reproduces `ear-live-shadow-trial`'s live-shadow result. Right removes seven shallow upper/rear fragment triangles from each copied male ear, classified by position and proximity to the actual head surface; the raised rim is retained. The female copies have identical ear indices. Head, body and ear vertex positions and colours are unchanged, and both sides use the same live shadow settings. No source/game character or previous trial is replaced. Ear asset provenance: CC0 MakeHuman-derived, see `../head-reference/README.md`.

The prominent scalp flap is reduced in the compared views; a slight light edge near the upper ear and strong cast shadows can still be visible. The trimmed ear remains separate from the head, has open cropped edges and is not a watertight weld. Artistic acceptance, animation, hair, mobile hardware performance and all lighting scenarios are not validated. The 4096-square live shadow map is for this isolated study only.

Desktop/mobile browser checks exercised both profile/view and light controls, compared face/body and ear vertex/color data, checked no female index change, exactly seven removed triangles per male ear, and the same live-shadow flags. `npm run verify` passed 232 tests. PNGs for both profiles, fronts, light positions and enlarged crop: `docs/previews/male-ear-fragment-trial/`.

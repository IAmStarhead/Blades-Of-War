# Original character silhouette — experimental study

A copy-only follow-up to `../game-head-form/`. Both original game heads are compared against deformed clones. The male upper forehead projects forward in profile and the lower jaw is broadened; the female lower face/chin is narrowed and its forward projection reduced. Old ear-disc triangles and the associated side bumps are removed entirely on trial copies. The face texture/UVs remain unchanged, and hair/beard are hidden. The head retains its original top height; details still require artistic review. This is not a finished anatomy, replacement head, or game integration.

The head and body are separate as in the original game and a join remains visible. The angular look of the female jaw, the male jaw, and mouth are not fully resolved; no facial animation has been added. The original character geometry and earlier studies are untouched. `tests/game-head-silhouette.mjs` checks clone isolation, index omission, finite data and texture coordinates.

Run Vite and open `/src/game-head-silhouette/`. Screenshots: `docs/previews/game-head-silhouette/`.
